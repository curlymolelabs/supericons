Part 1: What We Have Today

The Current Product (Verified from Codebase)

Agentic AI Kit (8 SVG generation variants, experimental). Status Feedback (CSS animations). Sold via Stripe. Honest assessment: early experiments, not finalized productions.

SVG-to-PNG (16-2048px). PNG-to-SVG tracing (6 trace profiles, 2 quality modes). Input inspection with risk analysis. Pro workflow tool.

Part 2: What We Need to Build

Prioritized Build Queue

Ordered by priority. Each step generates revenue or adoption independently.

P1

Agent Lifecycle Collection (9 icons)

Design 9 SVGs for AI agent states that no library has: idle, planning, executing, waiting, blocked, completed, failed, monitoring, learning. Include CSS animations and si:icon metadata. Sell at $29-49. Kill metric: 50 sales in 3 months.

P2

request_semantic_icon MCP Tool

One new MCP tool that accepts intent (concept + context) instead of keywords. Initially resolves only against the Agent Lifecycle pack. Proves the protocol thesis.

P3

Trust/Authority + Risk Collections (14 icons)

Trust and Authority (8): human/agent-initiated, confidence, verified, audit, override. Risk (6): irreversible, high-risk, cost, data exposure, rate limit, cascading. Sell individually or as $99 bundle.

P4

Grammar Primitives

State ring, confidence badge, authority marker, risk stripe. Composable building blocks that let icons express compound states.

P5

si:// Specification

Publish the formal spec: namespace schema, URI format, grammar rules, state machines, semantic events. Makes the standard real and referenceable.

P6

<si-icon> Web Component

One Web Component: accepts name + state, manages transitions, handles a11y, emits semantic events. Published as @supericons/components.

P7

Pro MCP Subscription ($12/mo)

Split MCP into free (keyword search) and pro (intent resolution + stateful animations + grammar + governance packs). Recurring revenue.

P8

Ecosystem Tooling

@supericons/reader library, CI/CD linter, VS Code extension, framework wrappers. Only after the standard is proven.

Explicitly Deferred

What We Do NOT Build Yet

Blockchain / NFT

May never be needed. If ever added, invisible infrastructure only.

Enterprise Audit Dashboards

Too early. Wait for standard adoption.

Framework Integrations

Vercel AI SDK, AG-UI, LangChain: wait for si:// to mature.

Hero Messaging Change

Keep "20,000+ free icons" until governance packs are proven with revenue.

Where we are: A polished icon search aggregator with solid MCP distribution and experimental premium packs.

Where we are going: The visual protocol for AI-native software. Icons for agent states that no one else has, with embedded meaning, composable grammar, and intent-based delivery.

The bridge: Ship one governance collection. If it sells, the vision is alive. If not, we still have the best icon search engine on the market.
