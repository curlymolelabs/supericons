Set up SuperIcons MCP in Cursor

Use Cursor with SuperIcons MCP when you want icon search and SVG retrieval inside the same editor flow as your code assistant and patching workflow. 

{
  "mcpServers": {
    "supericons": {
      "command": "npx",
      "args": ["-y", "supericons-mcp"]
    }
  }
}

Cursor flow

1. Add the MCP entry

Open Cursor MCP settings and place the supericons server entry in the config surface your installation uses.

2. Reload MCP servers

Cursor should show the server in its MCP tool list after the config is saved and reloaded.

3. Test with a UI prompt

Ask Cursor to search for a concrete icon use case like auth, charts, or navigation to validate the setup.

4. Apply the result in code

Once the icon is selected, have Cursor insert the SVG directly into the file it is already editing.

Premium access

What to connect

Premium MCP access requires your Supericons entitlement and a valid SUPERICONS_API_KEY in the Cursor MCP server entry.

What to do first

Generate the key in API Keys, add it to the env or secrets field Cursor uses for the supericons server, then reload MCP servers.

Troubleshooting

Cursor cannot see the server

Reload Cursor's MCP config after saving. Most issues here come from a stale server registry rather than a bad config block.

The command does not run

Make sure Node.js and `npx` are available to the shell environment Cursor launches for MCP tools.

Premium collections are missing

Cursor can still use the free 20,000+ icons without a paid plan. Premium results require the right purchase or Pro access plus a valid SUPERICONS_API_KEY.
