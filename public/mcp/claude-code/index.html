Set up SuperIcons MCP in Claude Code

Use Claude Code with the SuperIcons MCP server when you want icon search and SVG retrieval inside the same coding loop as edits, refactors, and UI iteration. 

# macOS / Linux
claude mcp add supericons -- npx -y supericons-mcp

# Windows
claude mcp add supericons -- cmd /c npx -y supericons-mcp

If you manage Claude Code config as JSON instead of CLI commands, use the same command and args values in the MCP server entry Claude Code reads.

Claude Code flow

1. Add the server

Run the Claude CLI command above to register the local supericons MCP server.

2. Confirm Claude can see it

Use claude mcp list or restart the session so Claude Code discovers the new tool cleanly.

3. Verify with a search

Ask Claude Code to find an icon for a small UI task, then confirm the results come back from SuperIcons.

4. Pull SVG into code

Once the search result looks right, ask Claude Code to insert the SVG directly into your component or markup.

Troubleshooting

Server does not appear

Run claude mcp list or restart the session after adding the server. Most failures here are stale registry issues.

Windows cannot launch npx

On native Windows, use cmd /c npx -y supericons-mcp instead of calling npx directly.

Premium icons are missing

Free icons work without a paid plan. Premium collections require the right SuperIcons entitlement or MCP key.
