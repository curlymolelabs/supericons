Quickstart

Start with the base MCP server config. Free icons work immediately. Premium icons require account entitlement plus a Supericons API key.

{
  "mcpServers": {
    "supericons": {
      "command": "npx",
      "args": ["-y", "supericons-mcp"]
    }
  }
}

Free path

  • Add the base MCP config.
  • Restart or reload your MCP client.
  • Use search_icons or get_icon right away.

Premium path

  • Subscribe to Pro or buy the premium pack you need.
  • Open Supericons API Keys and generate an API key.
  • Add SUPERICONS_API_KEY in the env or secrets field your client supports.

Premium MCP setup

The API key does not create entitlement by itself. It carries the access your account already has through Pro or purchased packs.

{
  "mcpServers": {
    "supericons": {
      "command": "npx",
      "args": ["-y", "supericons-mcp"],
      "env": {
        "SUPERICONS_API_KEY": "your_key_here"
      }
    }
  }
}

This JSON-style example fits clients that support an env object in their MCP config. Use the client-specific guide for the exact syntax your editor expects.

Troubleshooting

Server installed but no tools appear

Restart or reload the MCP client after changing config. Many setup failures are registry refresh issues.

Premium icons do not appear

Check that your account actually has Pro or purchased pack access, then regenerate or replace the API key in your MCP config.

Invalid or revoked key

Open API Keys, revoke the old key if needed, generate a new one, and update the MCP env or secrets field.

Need exact client syntax

Use the client guides above when your editor uses a different MCP config format than the JSON-style example on this page.
