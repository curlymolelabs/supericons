What Made V5 Work

A journal of the design process, failures, breakthroughs, and a reusable playbook.

2026-03-23 · Agentic AI Kit Icon Design

The Journey: V1 to V5

V1: Hand-drawn Outlines
Rough geometry, inconsistent weight, generic metaphors.
User: "the design of the icons is not up to standard"
V2: Better Outlines + Duotone
Researched Apple, Linear, Stripe systems. Drew better, added duotone. Still hand-drawn.
User: "slightly better but still not good enough. Can we not use the duotone?"
V3: 5-Layer Volumetric Neon
Extraordinary CSS styling (shadow, glow, fill, core, rim light). Shapes still amateur.
User: "the shape and design of the icons rather than the color, tone and style"
V4: Solar Icons (24x24) + Squircle
Used real icon library paths. Better, but 24x24 grid = low precision. Some metaphors wrong.
User: "better but still can improve. use mind mapping and socratic prompting"
V5: Phosphor Icons (256x256)
10x path resolution. Right metaphors. Production-quality shapes.
User: "YES! this is what I want. this is the level up baby!"

The Pattern of Failure

V1-V4 all made the same mistake

Every version invested more effort in styling (colors, gradients, glow effects, squircle backgrounds) while neglecting shape quality. It is the equivalent of buying premium paint for a poorly built house.

The user said "shapes matter more than style" three times before the message fully landed.

The 3 Breakthroughs

1. Phosphor Icons (256x256 grid)

This was THE single biggest change. Phosphor uses a viewBox="0 0 256 256" coordinate space versus Solar's viewBox="0 0 24 24". That is 113x more coordinate resolution for bezier control points.

At 96px rendering: a 24x24 path has ~4px per grid unit (chunky). A 256x256 path has ~0.375px per grid unit (silk smooth).

2. Shape First, Style Second

V5 used the exact same styling as V4 (same gradients, same squircle, same 3 palettes). Only the SVG paths changed. And that alone was enough to cross the quality bar.

Icon quality = 80% path geometry + 20% styling.

3. Right Metaphors via Socratic Prompting

For each icon, asked: "If I show this to a developer building an AI tool, will they IMMEDIATELY know what it is WITHOUT a label?"

This killed bad metaphors: pin-for-model became brain. Person-silhouette-for-agent became robot. Clock-for-latency became speedometer.

What the User's Prompts Did Right

The user's iterative feedback was the forcing function. Each prompt reframed the problem more precisely:

#User Prompt (Paraphrased)Effect
1 "Not up to standard. Research Apple, Linear, Stripe." Sent me to study premium brand design systems
2 "Can we not use duotone? Something extraordinary." Killed a dead-end approach, opened new directions
3 "Shapes matter more than color, tone, and style." The key reframe. Separated shape from style.
4 "Iconify is a huge resource. For shapes, use that." Pointed me to the right source for production paths
5 "Use mind mapping and Socratic prompting." Forced metaphor rethinking + research into Phosphor
Lesson: The user does not need to know the solution. They need to accurately describe the problem. Prompt #3 was the turning point because it correctly identified that shape quality, not styling, was the bottleneck.

The Reusable Playbook

1

Source shapes from Phosphor (256x256)

Use the Iconify API: https://api.iconify.design/ph:{icon}.svg. Never hand-draw SVG paths. The 256x256 grid produces visibly smoother bezier curves than 24x24 libraries.

2

Validate every metaphor with the "No Label" test

Show the shape (no label, no color) to someone. Can they identify the concept? If not, the metaphor is wrong. Use Socratic prompting: "What does a developer EXPECT this icon to look like?"

3

Lock shapes BEFORE styling

Do not add gradients, glows, squircle backgrounds, or color palettes until every shape passes the squint test. Styling cannot save bad geometry.

4

Apply the squint test

View all icons at 24px on dark background. Squint. Icons should have consistent visual weight (no icon should look dramatically heavier or lighter than the others).

5

Ship dual format

Always generate both Filled (inline, currentColor) and App-Icon (gradient squircle) formats. Doubles perceived value, costs almost nothing extra.

TL;DR

Stop styling. Start sourcing. Icon quality is 80% path geometry, 20% color/effects. Use Phosphor Icons (256x256 grid) via the Iconify API as your primary shape source. Validate metaphors with the "no label" test. Style last.
