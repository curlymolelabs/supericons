Premium Icon Bundle

Design Workflow: 10-Step Process

IDEO Design Thinking + Socratic Prompting

Phase 1: Empathize Who and Why

01
Define the Buyer Persona

Before drawing a single pixel, answer:

  • Who is buying this bundle? (e.g., "indie dev building an agentic AI tool")
  • What stack are they using? (React? Flutter? Figma?)
  • What design skill do they have? (Can they modify SVGs?)
  • What are they building? (SaaS dashboard? Mobile app?)
  • Budget sensitivity? ($19 impulse buy vs. $49 considered purchase)

Deliverable: A one-paragraph buyer brief.

02
Map the Buyer's Journey

Walk through the user's actual app and identify where icons appear:

Launch → Sidebar Nav → Dashboard → Data Display → Settings → Empty States → Errors → Onboarding

For each screen, ask: What icons does this screen require? What "gap" icons do not exist in any free library?

Deliverable: A screen-by-screen icon inventory.

Phase 2: Define What Exactly

03
List Every Icon Needed

Create a flat list grouped by function. Target: 30-50 icons per bundle.

GroupExample IconsCount
Navigationhome, menu, back, search, close, settings6
Statussuccess, error, warning, info, loading, offline6
Actionsadd, edit, delete, save, copy, share, download7
Domain-Specific(unique to this bundle's theme)10-15
Empty Statesno-data, no-results, first-time, maintenance4

"Does this icon already exist in the free Supericons library in a matching style? If yes, do not include it. The bundle must contain icons you cannot trivially find for free."

04
Define the Visual Brief

Lock down ALL design parameters before any icon is drawn:

ParameterOptions
Grid24x24 or 20x20
Stroke width1px (thin), 1.5px (standard), 2px (bold)
Corner radiusSharp (0), Slight (1px), Rounded (2px), Full
Cap styleRound, Square, or Butt
Join styleRound, Miter, or Bevel
Fill styleOutline, Solid, Duotone, or Mixed
Style reference"Like Lucide", "Like SF Symbols", "Like Phosphor Thin"

"If I place any 3 icons from this set side by side, do they look like they were designed by the same person in the same session?"

Deliverable: A one-page visual spec sheet with a reference "key icon."

Phase 3: Ideate Design the Proof

05
Draw the Key Icon

Pick the single most representative icon and design it first. This icon establishes the stroke weight, padding, corner radius, and detail level for the entire set.

  1. Set up a 24x24 artboard with 2px padding zone (20x20 live area)
  2. Draw using paths only (no text, no embedded images)
  3. Preview at 16px, 24px, 32px, 48px for legibility
  4. Test on dark (#111) and light (#faf8f4) backgrounds

"At 16x16, can a user still identify what this icon represents without a label?"

06
Draw 5 Proof Icons

Before committing to 30-50, draw 5 more spanning different structural types:

TypeExampleTests
Simple geometriccircle-check, squareStroke consistency
Complex compositedashboard (multi-shape)Visual weight balance
Organic/curvedleaf, brain, cloudCorner radius consistency
Directionalarrow, chevron, sendOptical alignment
Text-adjacentalert-badge, notificationSmall detail legibility

"Do these 6 icons feel like a family? Could I swap any one for a Lucide icon and it would look out of place?" If a free icon blends in, your style is not differentiated enough to charge for.

Phase 4: Prototype Full Production

07
Produce the Full Set

Per-icon production checklist:

  • Drawn on correct grid (24x24 with 2px padding)
  • Stroke width matches spec
  • Corner radius matches spec
  • All paths properly closed
  • No stray points or invisible paths
  • Icon centered horizontally and vertically
  • viewBox="0 0 24 24" set correctly
  • fill="none" stroke="currentColor" for outline icons
  • Preview at 16px, 24px, 48px: all legible
  • Dark and light background tests pass
08
Optimize and Export

SVG Optimization: SVGO cleanup, strip fixed width/height, ensure stroke="currentColor", remove inline styles, validate in browser.

Bundle contents:

FolderContents
/svg/All raw optimized SVGs
/react/JSX components (auto-generated)

Phase 5: Test Validate and Ship

09
Quality Audit

Visual audit: Print all icons on one sheet at 4x. Circle any that feel "off." Show to 2-3 people: "Do these look like one set?"

Technical audit:

  • All SVGs valid XML
  • All use currentColor (no hardcoded hex)
  • Consistent viewBox
  • No icon exceeds 2KB (target: under 500 bytes)
  • Total ZIP under 500KB

"Would I pay $29 for this bundle if I found it on Gumroad?" If the honest answer is "maybe," add more icons or improve quality until the answer is "yes, immediately."

10
Package and List

Listing requirements:

  • Hero image: 1200x630, 12-16 icons on dark grid
  • Bundle name, description, icon count, formats
  • Live preview in Supericons app ("Premium" library filter)
  • Price: $19-29 individual, $49-79 team/unlimited
