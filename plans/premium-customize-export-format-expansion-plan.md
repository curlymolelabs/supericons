# Premium Customize Export Format Expansion Plan

Date: 2026-04-09

## Goal

Add new export format options to the premium collection customize panel in this exact priority order:

1. React
2. Base64 and HTML
3. Vue
4. Svelte

`ICO` is explicitly excluded.

## Scope

- Expand premium customize-panel export options for owned premium icons.
- Keep existing export controls and behavior working:
  - `Download Animated SVG`
  - `Copy Animated SVG`
  - `Copy SVG (static)`
  - `Download PNG`
- Preserve current animation contract:
  - exported outputs must still honor active color, stroke width, speed, and export trigger settings
- Preserve current purchase and access protection measures.

## Out Of Scope

- No `ICO` export for premium customize panel.
- No server-side render/conversion pipeline changes.
- No changes to checkout, entitlement logic, or subscription rules.
- No redesign of panel layout beyond the minimal UI additions needed for new export buttons.

## Current-State Audit (Code)

- Premium export UI is rendered in [`store.js`](/d:/Personal/Business/Curly%20Mole%20Labs/Experiments/Apps/DailySprint/supericons/store.js) within `renderPremiumPanel()`.
- Premium export handlers are wired in [`store.js`](/d:/Personal/Business/Curly%20Mole%20Labs/Experiments/Apps/DailySprint/supericons/store.js) inside `wirePremiumPanelEvents()`.
- Animated SVG output is generated by `buildAnimatedSvg(...)` and already includes:
  - premium standalone class contract
  - trigger-mode rewriting (`loop`, `hover`, `once`)
  - speed multiplier
  - XML-safe style escaping
- Static SVG output is generated by `buildStaticPremiumSvg(...)`.
- Locked/non-purchased flow is separately handled via `showPremiumLockedPanel(...)`; export controls are only shown in owned path.

## Design Principles

- Reuse existing premium SVG builders; do not duplicate animation logic.
- Generate all new formats from the same finalized export payload used by existing SVG actions.
- Keep protection posture unchanged: no new path that bypasses ownership or auth.
- Keep new UI compact and grouped under existing `Export` section.

## Export Formats To Add

### Phase 1 (Highest): React

- Add `Copy React` for premium animated output.
- Generated React code should preserve animation fidelity without fragile SVG-attribute conversion.
- Recommended approach:
  - export as a component wrapper that renders trusted inline SVG markup from a string constant
  - avoid brittle global replacement of SVG attributes such as `class` -> `className` and dashed props

### Phase 2: Base64 + HTML

- Add `Copy Base64` for premium animated SVG data URI.
- Add `Copy HTML` for embeddable HTML snippet using the finalized animated SVG payload.
- Ensure copied HTML snippet works standalone without external CSS dependency.

### Phase 3: Vue + Svelte

- Add `Copy Vue` for premium animated output.
- Add `Copy Svelte` for premium animated output.
- As with React, prefer wrapper-based embedding of the finalized SVG markup over risky full AST conversion in this phase.

## Technical Plan

### Phase A: Shared Premium Export Payload Helpers

- Add a small helper layer in [`store.js`](/d:/Personal/Business/Curly%20Mole%20Labs/Experiments/Apps/DailySprint/supericons/store.js):
  - `buildPremiumAnimatedExportSvg(selection, premiumPanelState)`:
    - internally calls `buildAnimatedSvg(...)`
  - `buildPremiumStaticExportSvg(selection, premiumPanelState)`:
    - internally calls `buildStaticPremiumSvg(...)`
- Use these helpers in all existing and new premium export handlers to keep one source of truth.

### Phase B: Code-Generation Helpers (Premium)

- Add premium-specific code generation helpers in [`store.js`](/d:/Personal/Business/Curly%20Mole%20Labs/Experiments/Apps/DailySprint/supericons/store.js):
  - naming helpers for component names from `iconName`
  - safe template literal escaping for embedded SVG strings
  - `svgToBase64DataUri(svg)`
  - `buildPremiumReactCode(name, svg)`
  - `buildPremiumHtmlSnippet(svg)`
  - `buildPremiumVueCode(name, svg)`
  - `buildPremiumSvelteCode(name, svg)`

Implementation note:

- Wrapper-based code generation is preferred for v1 to minimize regressions from JSX/Vue/Svelte SVG attribute normalization edge cases.

### Phase C: Premium Panel UI Additions

- Extend the premium `Export` section in [`store.js`](/d:/Personal/Business/Curly%20Mole%20Labs/Experiments/Apps/DailySprint/supericons/store.js):
  - add a new compact sub-group for `Code` copy actions
  - button order must follow priority:
    1. `Copy React`
    2. `Copy Base64`
    3. `Copy HTML`
    4. `Copy Vue`
    5. `Copy Svelte`
- Keep `ICO` absent.
- Add minimal style updates in [`style.css`](/d:/Personal/Business/Curly%20Mole%20Labs/Experiments/Apps/DailySprint/supericons/style.css) only if needed for spacing and readability.

### Phase D: Event Wiring

- Add new button handlers in `wirePremiumPanelEvents()`:
  - each handler builds animated payload from shared helper
  - each handler copies generated code/text to clipboard
  - each handler has explicit success/failure toast
- Keep existing handlers untouched functionally, but migrate to shared helper payload for consistency.

### Phase E: Protection and Dependency Safety

- Do not modify:
  - entitlement checks in premium purchase flow
  - locked-panel logic
  - premium asset function access rules in [`supabase/functions/serve-premium-asset/index.ts`](/d:/Personal/Business/Curly%20Mole%20Labs/Experiments/Apps/DailySprint/supericons/supabase/functions/serve-premium-asset/index.ts)
- Ensure no export actions are available in locked/non-owned states.
- Ensure exported content derives only from already-loaded owned-selection data path.

### Phase F: Analytics (Recommended)

- Add lightweight tracking events for new premium export actions to measure adoption by format.
- Proposed event payload:
  - `collectionSlug`
  - `iconName`
  - `format`
  - `playMode`
  - `colorMode`

## Verification Matrix

### Functional

- `Copy React` outputs valid code and preserves animation behavior.
- `Copy Base64` outputs valid `data:image/svg+xml;base64,...`.
- `Copy HTML` outputs a runnable snippet with working animation behavior.
- `Copy Vue` outputs valid SFC-style snippet.
- `Copy Svelte` outputs valid Svelte snippet.
- Existing premium exports still work exactly as before.

### Trigger/Playback Parity

- For each new format, verify output semantics under:
  - `Loop`
  - `Hover`
  - `Play once`
- Verify copied payload reflects active speed multiplier.

### Appearance Parity

- Verify copied payload reflects:
  - original/custom color mode
  - selected color
  - stroke width when supported

### Protection Regression

- Non-owned premium icon still shows locked panel with no export buttons.
- Owned premium icon still shows full customize + export controls.
- No change to premium asset access enforcement path.

### Browser and DX Sanity

- Paste React/Vue/Svelte outputs into minimal sample files and confirm compile/run.
- Verify clipboard payload size remains practical and no truncation occurs.

## Risks And Mitigations

- Risk: Framework snippets can break if we do naive SVG attribute conversion.
  - Mitigation: use wrapper-based embedding in v1.
- Risk: Multiple code buttons may crowd narrow panel width.
  - Mitigation: keep compact button styling and allow controlled wrapping.
- Risk: New exports diverge from existing animated payload.
  - Mitigation: all formats must source from shared `buildPremiumAnimatedExportSvg(...)`.
