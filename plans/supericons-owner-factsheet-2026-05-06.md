# Supericons Owner Factsheet

Date: 2026-05-06

Purpose: internal owner-facing snapshot for decision making, partner calls, launch planning, and keeping the product story consistent.

## Short Summary

Supericons is an icon search and workflow platform for modern builders, designers, and AI coding agents.

The product is not only an icon library. It combines:

- human browser search
- MCP search for AI agents
- semantic icon metadata
- SVG retrieval and exports
- Motion Lab animation workflows
- Converter workflows for SVG and PNG
- premium access through API keys

## Current Product Position

Best current positioning:

> Supericons helps humans and AI coding agents find, choose, and use the right icon faster.

Sharper public version:

> Semantic icon search, MCP access, Motion Lab, and converter tools for modern builders.

Owner interpretation:

Supericons should not compete only on icon count. Larger catalogs can copy that. The stronger wedge is icon decision quality plus workflow depth:

- search by meaning, not only file name
- recommend icons for UI slots
- retrieve SVGs directly inside coding agents
- animate icons through Motion Lab
- convert assets through Converter
- support both human designers and AI-first builders

## Product Surfaces

### Browser Search

For humans browsing and copying icons.

Useful for:

- designers choosing icons visually
- frontend developers searching quickly
- indie builders building dashboards, apps, landing pages, and internal tools

### MCP

For AI coding agents.

Useful for:

- finding icons without leaving the IDE
- recommending coherent icon sets for dashboards and navigation
- retrieving SVG code directly
- reducing weak default icon choices from AI-generated UI

### Motion Lab

Premium/pro workflow for animated icon output.

Useful for:

- hover states
- loading states
- status feedback
- product polish
- hero/feature motion
- animated SVG and CSS output

### Converter

Premium/pro workflow for format conversion.

Useful for:

- converting SVG to PNG
- tracing PNG to SVG
- preparing assets for UI, docs, social posts, or design systems
- reducing dependence on separate conversion tools

## Strategic Strengths

- Supericons has both human and AI-agent workflows.
- The semantic registry is a defensible quality layer if maintained carefully.
- MCP distribution gives Supericons a new channel close to AI builders.
- Motion Lab and Converter make the product more than a search page.
- The public GitHub wrapper provides discoverability without open-sourcing the private product code.

## Strategic Risks

- Icon search is a crowded red ocean.
- Bigger competitors may have more icons or cleaner directory presence.
- Weak documentation can cause users to fail MCP setup.
- If semantic tags degrade, the core search promise weakens.
- If Motion Lab and Converter are hidden, users may think Supericons is only a free icon search site.

## Messaging Guardrails

Lead with:

- semantic search
- MCP for coding agents
- icons for humans and AI agents
- Motion Lab and Converter as workflow tools
- faster icon choice, less browser hopping

Avoid leading with:

- internal registry architecture
- Supabase/database details
- internal agent review history
- full private source details
- exaggerated claims about proprietary AI
- "best in the world" style claims without proof
