0 Brand Synopsis

Supericons is a free, open-source icon search engine and customization platform built for modern UI/UX designers and frontend developers. Rather than being a single icon library, it unifies 19,000+ icons from 9 of the best open-source libraries (Material Symbols, Lucide, Tabler, Phosphor, Heroicons, Bootstrap, Ionicons, Iconoir, and Simple Icons) into one searchable, customizable workspace.

Core Problem: Developers waste 5 to 15 minutes per icon going from browse to production. Supericons cuts that to 5 seconds.

Powered by AI semantic search (220+ synonym groups, 5-layer matching), true Material Symbols variable font axes, and one-click component export (React, Vue, Svelte, HTML), Supericons gives creators the “superpower” to find, customize, and ship icons faster than any tool on the market. The brand stands for speed, precision, and zero friction, distilling the fragmented icon ecosystem into a single, instant workflow.

Logo Identity

Ultra-minimalist, flat SVG geometry. No gradients, no complex shading, no literal clichés. A single, memorable silhouette that balances the “Super” aspect (speed, power, aggregation) with the digital nature of “Icons” (clean geometry, pixel precision). The mark should feel at home as a favicon, an app icon, and a watermark on exported ZIP files.

1 Socratic Prioritization

Q1. What does the user open the app to do?

Search → Customize → Export. Export is where value is delivered. If the output doesn't fit their stack, the entire visit was wasted.

Q2. Where does the current experience break?

StepFrictionSeverity
SearchSynonym search works (30+ groups). Cross-library results now span 20,880 icons.Medium
Browse9 libraries, 16,483 outline + 4,397 solid icons. Outline/solid toggle live. Color bugs fixed.Low
ExportReact, Vue, Svelte, HTML done. PNG + SVG download. Angular/Flutter missing (low demand).Low

Q3. Which gap, if closed, unlocks the most users?

BuildEffortImpactMoat?
Multi-framework export~1 sessionHigh — unlocks 80% more devsMoat #3
More libraries (50K+)~2–3 sessionsHigh — 5x icon countEnables Moat #1
AI semantic search~3–5 sessionsVery High — key differentiatorMoat #1

Q4. What's the right sequence?

Verdict: Export (quick moat win) → Libraries (data foundation) → AI Search (biggest moat, needs the data). Multi-framework export is a 1-session build that immediately unlocks the majority of the developer audience.
