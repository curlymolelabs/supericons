1 Revenue Model

Three-tier pricing that separates downloadable assets (own forever) from ongoing services (access-based). This prevents the “subscribe, download, cancel” problem.

Impulse Pack
$5-9 one-time
1 themed pack (10 animated icons)
  • 10 CSS-animated SVG icons
  • Demo/preview HTML page
  • Full color/size customization
  • Commercial license
  • Own forever after purchase
Curated Bundle
$19-39 one-time
3-5 packs (30-50 icons), handpicked
  • Multiple themed packs
  • Version-locked (at time of purchase)
  • Bundle discount vs individual
  • Commercial license
  • Own forever after purchase
Pro Subscription
$9/mo or $79/yr
All packs + live tools + API + exclusives
  • All current + future packs
  • Online customizer tool
  • API access (CI/CD, MCP)
  • Pro-exclusive packs
  • Monthly new drops
  • Priority theme requests

2 Subscribe-and-Cancel Defense

Problem: “I’ll subscribe for $9, download all packs, cancel next month.”

The subscription’s value is split between downloadable files (keep after cancel) and live services (revoked on cancel):

FeatureDownload and keep?Stops on cancel?
Animated icon CSS filesYesNo
Online customizer toolNoYes
API access (CI/CD, MCP)NoYes
Monthly new pack dropsPartialYes (no future access)
Pro-exclusive packsNoYes (access revoked)
Priority theme requestsNoYes

Why $9/mo works: Above the $5-9 impulse pack (no arbitrage). Below Lordicon’s $16/mo (competitive). $79/year ($6.58/mo effective) rewards annual commitment without “lifetime” risk.
