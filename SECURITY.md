# Security

Supericons MCP provides read-only icon search, recommendation, retrieval, preview, and library listing tools.

The hosted endpoint and free local setup do not need a Supericons account or API key. The local setup starts the public `@supericons/mcp` npm package through `npx`.

For Pro tools or premium icon access, use `SUPERICONS_API_KEY` as an environment variable. Keep API keys out of screenshots, public issues, shared config files, and source control.

Do not submit credentials, customer data, private source code, local file paths, or screenshots that reveal secrets in bug reports.

To report a security concern, contact Curly Mole Labs through the official Supericons website:

https://supericons.dev
