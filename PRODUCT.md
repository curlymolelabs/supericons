# Product

## Register

product

## Users

Icons Lab is for the Supericons founder, owner, or design lead creating high-quality icon assets without living inside a full vector suite. A secondary user is an AI agent that needs structured, reviewable operations for concept briefing, primitive creation, point editing, readability review, visual-weight comparison, and export preparation. A future user is a developer, designer, or pro customer creating custom icons, bento icon sets, or product-specific packs with guided agent help.

## Product Purpose

Icons Lab is a focused icon craft bench for creating, refining, reviewing, and exporting Supericons-grade icons. It exists to help humans and agents reliably produce beautiful, readable, consistent icon sets from a 24px icon-first workflow. Success means the user can start from intent, build editable geometry, review real-size previews, approve agent suggestions, and export clean assets without the tool becoming a general-purpose vector editor.

## Brand Personality

Precise, calm, taste-led. The product should feel like a disciplined icon workshop: quiet enough for focus, opinionated enough to prevent messy output, and flexible enough for a human owner to keep taste authority.

## Anti-references

Icons Lab should not feel like a smaller Inkscape, Figma, Illustrator, Photoshop, generic AI image generator, or dense professional vector suite. It should avoid noisy checklists, always-visible advanced controls, fake placeholder output, decorative UI, and agent actions that apply changes without review.

## Design Principles

1. Canvas first: the 24px board, safe area, keylines, and live preview are the center of the product.
2. Beautiful by default: the system should guide geometry toward readable, balanced, export-ready icons before exposing expert controls.
3. Human approval: agent work should be visible, reversible, and approved by the human before it changes the icon.
4. Progressive depth: primary tools stay visible; advanced operations appear only when the current selection needs them.
5. Export truth: canvas, preview, and exported SVG should agree on stroke, bounds, and visual weight.

## Accessibility & Inclusion

Icons Lab should target accessible product UI basics: readable contrast, keyboard-visible focus, reduced-motion-safe transitions, clear labels, and no reliance on color alone for important states. Icon review should include small-size readability because many users experience icons at 16px or 24px in dense interfaces.
