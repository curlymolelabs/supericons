Protecting the premium source

layered, honest, built on the registry's existing visibility model
Live demo: this preview is rasterized to a canvas with a watermark. There is no premium SVG in this page's DOM to inspect or copy, and right click is disabled on it.

Registry visibility gating exists today

Animated premium records ship as protected_premium_record, the access tier your registry already enforces. They never enter public/registry, MCP public artifacts, or search projections. Agents cannot fetch what is never published.

Raster-only previews this page demos it

Grid and panel previews render to canvas or server-generated PNG frames, watermarked. The animated SVG and its motion recipe only leave the server after a licensed purchase, delivered against an API key, the same flow Motion Lab Pro uses.

Per-customer fingerprinting planned

Each purchased SVG gets an invisible watermark: path point ordering and sub-pixel decimal jitter unique to the license. Leaked files trace back to the buyer without changing a visible pixel.

MCP behavioral guardrails planned

MCP tools return premium items as preview PNG plus metadata only, never source markup, until the session presents a licensed SUPERICONS_API_KEY. Rate limits and per-key watermarked delivery make bulk extraction expensive and attributable.

Honest limit: anything rendered on screen can be screen-recorded or manually redrawn, and a determined human can approximate any 24px glyph. The goal is not perfect DRM. It is protecting the source vectors and motion recipes, making extraction harder than paying $5, and making leaks traceable.
