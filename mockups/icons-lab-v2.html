4 · States

One icon, a full agent lifecycle, one CSS variable

Icons for agentic products are not static. Each icon ships as a state package: geometry variants plus motion tokens, all driven by --si-state so a host app flips states without swapping assets. Reduced-motion fallbacks are generated, not optional.

State playground · click a state

Consumer contract

/* host app flips one variable */
.si-agent-handoff {
  --si-state: loading;
}

/* motion tokens per state */
{
  "loading": {
    "geometry": "variant:loading",
    "anim": "dash-flow 900ms linear infinite",
    "reducedMotion": "static-dash",
    "aria": "Task transferring"
  }
}

Readiness: 6 of 7 states drafted. Missing: disabled. Ship gate requires every declared state to pass QA with a reduced-motion fallback and an aria label.

5 · Package

Formatting and conversion: every target from one source of truth

The icon document is the single source. Formats are projections, generated fresh on export so they can never drift. Internal notes, prompts and workspace data never enter any output.
