Humans see a beautiful animated icon. Agents receive the full machine surface: SVG markup, the state stylesheet, accessibility labels, and semantic metadata that says when to use it and when not to.

        
Your agent asks for an intent like agent.blocked_on_human and gets back a component it can drop into any framework, already matching your project palette.

        
Works today in Claude Code, Codex, Cursor, Cline, Windsurf and any MCP-capable client.
