40 custom glyphs, one per premium blast, no more borrowed emoji

Every premium sound currently fronts an emoji (✋ 👓 🐴 💨). This set replaces them with original glyphs drawn in one house style: 48 grid, 2.5px ink stroke, round caps, and a single accent per pack carrying the joke. IDs match src/lib/soundPacks.ts so the glyph field swaps straight over: cards, focal props, and reduced-motion quiet badges all inherit them. Click any card to copy its SVG.

Fit with the effects gallery: these glyphs are the identity layer; the existing CSS recipe effects stay as they are. The focal-prop primitive can render the SVG at 24vmin instead of an emoji, and the quiet badge uses the same glyph at 3rem. Emoji stays as a legacy fallback for unmapped sounds.
