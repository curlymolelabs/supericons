Claude Code

Set up Supericons MCP in Claude Code

Add icon search and SVG retrieval to Claude Code without leaving the command line. Search, pick, and insert icons in the same session as your code edits.

Back to docs Pricing 
# macOS / Linux
claude mcp add supericons -- npx -y supericons-mcp

# Windows
claude mcp add supericons -- cmd /c npx -y supericons-mcp

Prefer JSON config over CLI? Use the same command and args values in your Claude Code MCP server entry (~/.config/claude-code/mcp.json or equivalent).

Claude Code flow

1 Add the server

Run the Claude CLI command above to register the supericons MCP server.

2 Confirm Claude can see it

Run claude mcp list to verify the server registered, or restart the session if it is not listed.

3 Verify with a search

Ask Claude Code to find an icon (e.g., a settings or navigation icon) and verify that the results include Lucide or Tabler options.

4 Pull SVG into code

Once the icon is selected, ask Claude Code to insert the SVG directly into your component or markup.

Example prompt

Find a settings icon from Lucide for a dashboard header.
Return two alternatives from Tabler as well.
Then insert the chosen SVG into my React component.

Premium access

How premium access works

Premium icons are not unlocked simply by adding a key. They unlock when your Supericons account has an active Pro subscription or purchased collection, and SUPERICONS_API_KEY is present in the MCP server config Claude Code uses at startup.

What to do

Sign in to Supericons, generate an API key from the API Keys page, then add that key in the env or secrets field Claude Code uses for MCP server configuration.

Troubleshooting

Server does not appear

Run claude mcp list after adding the server. If it still does not appear, restart the Claude Code session.

Windows cannot launch npx

On native Windows, use cmd /c npx -y supericons-mcp instead of calling npx directly.

Premium icons are missing

Free icons work without a Pro subscription. Premium collections require an active Pro subscription or purchased collection on your Supericons account, plus a valid SUPERICONS_API_KEY in your MCP server config.

Codex

Set up Supericons MCP in Codex

Add icon search to your Codex session. Find and insert icons without switching to a browser - search, pick, and drop SVGs in the same coding flow as your edits.

codex mcp add supericons -- npx -y supericons-mcp
[mcp_servers.supericons]
command = "npx"
args = ["-y", "supericons-mcp"]

The CLI command is the quickest path. Prefer a config file? Add the same values to ~/.codex/config.toml under [mcp_servers.supericons].

Codex flow

1 Register the MCP server

Run codex mcp add supericons -- npx -y supericons-mcp or add the same values to config.toml.

2 Confirm Codex can see it

Open Codex and use /mcp to confirm the server is active before you rely on icon tool calls.

3 Try a narrow prompt

Start with a concrete request like a navigation, auth, or dashboard icon so you can verify the flow quickly.

4 Insert the SVG

After selecting an icon, ask Codex to place the SVG inside your component or template file directly.

Example prompt

Search Supericons for a secure login icon.
Show me a Lucide option and a Tabler option.
Insert the Lucide SVG into the sign-in button component.

Premium access

Your account comes first

Your API key authenticates to your Supericons account. The collections and tools you can access depend on what your account owns - either a Pro subscription or purchased collection packs. The key alone does not grant access.

How to add your API key in Codex

Generate the key in API Keys, then add SUPERICONS_API_KEY to the env or secrets field your Codex MCP config uses for the supericons-mcp server.

Troubleshooting

Server saved but not visible in Codex

Use /mcp in Codex to inspect active servers and restart the session after changing MCP config.

The npx command does not run

Ensure npx is available in the shell environment that Codex uses for local MCP processes.

Premium icons do not appear

Free icons still return 20,000+ results without a Pro subscription. Premium icon access requires an active Pro subscription or purchased collection on your Supericons account, plus a valid SUPERICONS_API_KEY.

Set up Supericons MCP in Cursor

Add icon search and SVG retrieval to Cursor. Find and insert icons without leaving the editor - in the same session as your code edits and component builds.

{

Cursor flow

1 Add the MCP entry

Open Cursor settings, navigate to MCP, and paste the server config. Or add it directly to ~/.cursor/mcp.json.

2 Reload MCP servers

Save and reload. Verify the supericons server appears in Cursor's MCP tool list before continuing.

3 Test with a UI prompt

Ask Cursor to search for a concrete icon use case like auth, charts, or navigation to validate the setup.

4 Apply the result in code

Once the icon is selected, have Cursor insert the SVG directly into the file it is already editing.

Example prompt

Find an icon for a dashboard analytics tab.
Return one Lucide option and one Phosphor option.
Then replace the placeholder SVG in my sidebar component.

Premium access

What you need for premium access

Premium MCP access requires an active Pro subscription or purchased collection on your Supericons account, plus a valid SUPERICONS_API_KEY in your Cursor MCP server config.

What to do first

Generate the key in API Keys, add it to the env or secrets field Cursor uses for the supericons server, then reload MCP servers.

Troubleshooting

Cursor cannot see the server

Reload Cursor's MCP config after saving. Most issues here come from a stale server registry rather than a bad config block.

npx is not found or fails to start

Make sure Node.js and npx are available to the shell environment Cursor launches for MCP tools.

Premium collections are missing

Cursor can still use the free 20,000+ icons without a Pro subscription. Premium results require an active Pro subscription or purchased collection on your Supericons account, plus a valid SUPERICONS_API_KEY.
