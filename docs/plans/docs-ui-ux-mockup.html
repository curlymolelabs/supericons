Quickstart

Start with the base MCP server config. Free icons work immediately. Premium icons require a Pro subscription or collection (pack) purchase, plus a Supericons API key.

Paste the snippet below into your client's MCP config file. If you are not sure where to find it, pick your client from the guides below.

{
  "mcpServers": {
    "supericons": {
      "command": "npx",
      "args": ["-y", "supericons-mcp"]
    }
  }
}

Free path

  • Add the base MCP config to your client.
  • Restart or reload your MCP client.
  • Use search_icons or get_icon right away.

Premium path

  • Subscribe to Pro or buy a collection.
  • Open API Keys and generate an API key.
  • Add SUPERICONS_API_KEY in the env or secrets field your client supports.

Premium MCP setup

An API key securely links your coding agent to your Supericons account. It unlocks whatever premium collections or Pro workflow tools you already own.

{
  "mcpServers": {
    "supericons": {
      "command": "npx",
      "args": ["-y", "supericons-mcp"],
      "env": {
        "SUPERICONS_API_KEY": "your_key_here"
      }
    }
  }
}

This JSON-style example fits clients that support an env object in their MCP config. Use the client-specific guide for the exact syntax your editor expects.

Today MCP supports icon search, icon retrieval, library discovery, Motion Lab preset exports, and Converter workflows for Pro users.

MCP tools

search_icons

Find the closest icon match across the free libraries and any premium collections your account can access.

get_icon

Retrieve a specific icon payload with ready-to-use SVG output that can be inserted directly into code.

list_libraries

List the libraries and premium collection sources your MCP session can currently access.

list_motion_presets Pro

Browse available Motion Lab presets before generating CSS or animated SVGs.

export_motion_css Pro

Generate Motion Lab CSS for a chosen icon, preset, trigger, duration, and intensity without leaving your coding agent.

export_animated_svg Pro

Generate a self-contained animated SVG for the selected icon and preset as a single MCP response.

convert_svg_to_png Pro

Render SVG input to PNG with a controlled output width and optional background through the Pro converter workflow.

convert_png_to_svg Pro

Trace PNG input to SVG with the same converter-quality controls used by the browser workflow.

Access by plan

Free users can search and retrieve from all free libraries. Pro subscribers and collection owners can access their premium assets by connecting an API key.

Workflow tools require Pro

Motion Lab MCP and Converter MCP are Pro-only. Collection ownership unlocks premium icon assets, but workflow tool access requires a Pro subscription.

Workflow Tools

Motion Lab and Converter are free to browse in the browser. Exports (animation CSS, animated SVG, PNG, and SVG tracing) require a Pro subscription, both in the browser and through MCP.

Pro subscribers can also run both tools through MCP, triggering the same exports directly from their coding agent.

Troubleshooting

Server installed but no tools appear

Restart or reload the MCP client after saving your config. Most missing-tool issues are simply caused by the client needing a refresh.

Premium icons do not appear

Verify your account has an active Pro subscription or collection purchase, then generate a new API key and update your client's config.

Invalid or revoked key

Open API Keys, revoke the old key if needed, generate a new one, and update the MCP env or secrets field.

Need exact client syntax

Use the client guides above when your editor uses a different MCP config format than the JSON-style example on this page.
