Thematic Set System

Product Vision

Supericons as a human-and-agent icon creation system.

The goal is to help humans and AI agents create better themed icon sets faster, with meaning, style, motion, accessibility, and implementation guidance built in.

Core Positioning

Supericons is the visual meaning layer for agent-assisted software.

The System

Meaning first. Style second. Export third.

User Brief Theme Set Icon Meaning Style Adapter State Behavior Export
01

Theme Set

A practical product package for one use case, such as AI agent status, dating safety, or DevOps incidents.

02

Supericon Profile

The meaning contract. It says what the icon means, when to use it, when to avoid it, and how to describe it accessibly.

03

Visual DNA

The guardrails that keep an icon recognizable across styles. Short rules, not a giant design theory.

04

Behavior

The state and motion layer: static, active, hover, transition, and reduced-motion behavior.

05

Style Adapter

The visual treatment that adapts the same meaning to styles like Minimal Glass, Shadcn Minimal, or Terminal Mono.

06

Export

The practical output: SVG, animated SVG, React snippet, Web Component snippet, and JSON profiles.

MCP Tools

Expose the system to agents through clear tools.

list_theme_sets

Shows available practical icon systems.

recommend_theme_set

Matches a user brief to a set and adapter.

get_supericon_profile

Returns meaning, usage rules, accessibility, and files.

list_style_adapters

Shows available visual treatments.

compose_supericon

Combines meaning and style into a snippet or asset.

validate_supericon_usage

Checks whether the chosen icon fits the intended UI state.

Theme Set Format

{
  "id": "ai-agent-status",
  "name": "AI Agent Status",
  "target_apps": ["AI dashboard", "coding agent"],
  "default_adapter": "minimal-glass",
  "supported_adapters": ["minimal-glass", "shadcn-minimal"],
  "free_icons": ["ai-thinking", "ai-working", "pending-approval"],
  "paid_icons": ["blocked", "retrying", "low-confidence", "risk-high"]
}

Profile Format

{
  "id": "pending-approval",
  "meaning": "Progress is paused until a human decides.",
  "use_when": "Use when a human decision is required.",
  "avoid_when": "Do not use for errors, loading, or active work.",
  "not_instead_of": ["blocked", "ai-thinking", "ai-working"],
  "accessibility": {
    "role": "status",
    "label": "Pending approval",
    "live": "polite"
  }
}
