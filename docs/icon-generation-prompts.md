# Icon Generation Prompts — Batches of 50 Icons per Sheet

> Generated from 2025/2026 trend research. Each batch targets a high-demand app category with exactly 50 icons, designed for consistency at 24x24px grid, 2px stroke, rounded line caps/joins, SVG format.

---

## Global Style Rules (Apply to Every Batch)

- **Canvas:** 24x24px viewBox
- **Stroke:** 2px (uniform), rounded caps and joins
- **Style:** Minimal line icons (thin-to-regular weight), monochrome base with optional duotone fill variant
- **Consistency:** All icons must share the same visual DNA—consistent bounding box usage, consistent corner radius logic, consistent negative space
- **Output:** Individual SVG files + a single 50-icon reference sheet (10 columns x 5 rows)
- **Accessibility:** Each icon must be recognizable at 16x16px and crisp at 48x48px

## How to Use These Prompts

1. **Pick a batch** that aligns with your product or missing catalog gaps.
2. **Apply the Global Style Rules** to maintain consistency across all 50 icons.
3. **Generate in vector format** (SVG) with a 24x24px viewBox.
4. **Review at 16x16px** — if an icon falls apart, simplify it.
5. **Export a reference sheet** (10x5 grid) for quick visual scanning.
6. **Create filled/outline variants** where applicable for design system flexibility.
