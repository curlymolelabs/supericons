Design Notes

Pill Chips (from Pretext Rich Note)

Rounded pills are more compact than the old rectangular buttons. They wrap naturally in the horizontal quadrants (top/bottom) and stack vertically in the side quadrants (left/right). Each quadrant scrolls independently when content overflows.

Category Color Coding

Each quadrant has a colored dot + hover accent: green (Entrances), yellow (Attention), red (Exits), purple (My Animations). This provides instant visual grouping without needing to read labels.

Quadrant Scrolling

Top/bottom quadrants: max-height 72px, horizontal wrap + vertical scroll. Left/right quadrants: max-height 200px, vertical column scroll. This keeps the icon centered while fitting 20 presets per quadrant.

My Animations (Q4)

Bottom quadrant reserved for AI agent saved animations. Starts empty with placeholder text. As user saves custom animations, they appear here as purple-accented chips. Matches the existing "Saved" quadrant location.
