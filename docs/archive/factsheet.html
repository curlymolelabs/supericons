What it does

Supericons aggregates 20,000+ open-source SVG icons from 10 popular libraries into one searchable interface. It provides AI-powered semantic search, real-time customization (color, size, stroke, containers), and one-click export as SVG, PNG, React, Vue, or Svelte components.

For AI-assisted development, Supericons ships a dedicated MCP server (supericons-mcp) that lets coding agents search and paste icons directly into code, with no browser needed.

MCP Server

The Supericons MCP server lets AI coding agents search and retrieve icons directly inside the editor. Compatible with Claude Code, Codex, Cursor, OpenCode, Cline, GitHub Copilot, Windsurf, and Antigravity.

{
  "mcpServers": {
    "supericons": {
      "command": "npx",
      "args": ["-y", "supericons-mcp"]

  }
