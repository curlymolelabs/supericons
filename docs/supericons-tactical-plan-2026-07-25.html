T1 · next

Traffic classification and the organic denominator

Scope shrank after audit. classifyMcpTraffic already exists, already treats the cryptographically signed controlled-run marker as authoritative, and already preserves an unknown class. What is missing is probe detection inside live traffic, and a reported organic denominator.

Step 0 first: query the existing traffic_class distribution. If controlled-run labelling already catches most non-organic traffic, skip the detection build and go straight to T2. Do not build machinery the data says is unnecessary.

Done when: organic searches, organic identities, and unknown share are stated together and defensible; the rule re-runs unattended as code; popularity reads the organic stream. Rules: T1 rule spec.

Cross-channel icon popularity

Rank All Icons by recent evidence from web, hosted MCP, and local, per the PRD already written. Icon-level, not query-level: 87% of queries are unique, so query frequency is noise while confirmed icon use is dense.

The user-visible win. Fixes a live defect (the grid orders by an April snapshot), improves the default browse experience, adds indexable content, and is the first public proof of the living-data thesis.

T3 · complete

Resolve what estimated reach counts

Confirmed in production: hosted identity hashes IP, user agent, client family and month bucket, so it is month-stable, not session-scoped. 100% of hosted rows carried the hash; 153 identities recurred across days. The fallback concern is refuted.

Corrected by audit: a fingerprint is not a person. Just 12 user-agent hashes produced all 629 hosted identities, so the signal is close to an IP count. Read it as clients or networks.

Outcome: the earlier 4% registration rate is withdrawn: 27 all-time accounts over 632 recent identities compares two populations, and only 2 identities are account-linked. Conversion cannot be measured before rung 1. See the corrected finding.

T4

Rung 1: the identity primitive

Self-service free keys, synced collections, and an MCP tool to retrieve them. 95% of searches are anonymous agent traffic today, so nothing personal is possible before this exists. It is also the only thing that makes conversion measurable at all: today just 2 identities are account-linked.

Hard design constraint from the audit. The dominant channel has the weakest registration path: a user inside ChatGPT has no browser session and no reason to leave the conversation. If a key cannot be obtained and used from inside an agent conversation, registration stays flat regardless of how good the offer is. This is a structural explanation for 27 accounts, not a funnel-quality failure.

Build note: put the attribution choice in the issuance flow itself. An afternoon there, expensive to retrofit onto issued keys.

Done when: keys are self-service, collections sync, an MCP tool retrieves them, and attribution coverage rises measurably.

Parallel and deferred

Always on, no engineering

  • Diversification, not just distribution. The audit reframed this: at 96.5% of identities on one client, the task is no longer "get more traffic" but "get a second source." A ranking change inside one catalog is close to an extinction event for current traffic.
  • Second-channel candidates already partly seeded: Search Console and organic, the MCP registries, npm, and the directories that listed the repo unprompted.
  • Content. Expressive originals seeded by real observed zeros rather than intuition.
  • None of these should compete for the same hours as T1 to T6.

Deliberately deferred

  • Trust posture and public commitments. Parked by owner decision until they can be proven and there is something concrete to point at.
  • Paid advanced analytics. T5 must prove engagement first; pricing follows demonstrated use, not projection.
  • Public demand reporting. Hold until volume makes an honest version presentable: patterns without denominators would flatter the numbers.
  • Canvas, publishers, marketplace. Rings 3 to 5, after the loop closes once.

Why parked, and what changes it

  • A promise nobody can verify is a liability, not an asset
  • Backtracking on a published commitment costs more than never publishing one
