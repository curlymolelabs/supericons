Supericons MCP Output Quality Audit

Updated on 14 May 2026.

Scope

This audit covered human-facing MCP output for icon search, icon recommendations, Motion Lab, Converter, no-result hints, selector instructions, and Pro access messages.

The supported non-English locales are zh-Hans, zh-Hant, ja, ko, es, de, pt, ar, hi, vi, and th.

Findings

AreaFindingStatus
Motion Lab preset output Some English preset descriptions were generic. Non-English agents had to infer natural explanations from English-only metadata. Fixed by using the richer English Motion Lab metadata and adding locale-specific overlay fields.
Motion Lab localized output Preset names and UI labels were localized in the app, but MCP recipe outputs did not include localized descriptions, tone, or usage context. Fixed by adding a generated MCP locale data file and returning a localized block while preserving all original fields.
Converter help text Converter MCP option guidance was useful but English-only. Fixed by adding localized Converter guidance and trace-class explanations to inspect_converter_options.
No-result and access hints Search and Pro access hints were English-only. Improved by adding localized hint fields where a locale is provided.
Protocol safety Tool names, schema fields, IDs, library names, and file-format labels must not be translated. Preserved. Localized copy is additive and does not replace functional fields.

Changes Made

  • Added data/i18n/mcp-output-locales.json and mcp/generated/mcp-output-locales.json.
  • Added mcp/mcp-output-localization.js to attach localized output safely.
  • Added optional locale input to Motion Lab and Converter MCP tools.
  • Kept original English fields in place and added localized fields beside them.
  • Updated the Motion Lab MCP artifact generator to use stronger English descriptions.
  • Updated multilingual MCP verification to check all supported locales, placeholders, 80 presets, and Converter trace classes.

Translation Notes

DeepL was used for the first six locale sets: Simplified Chinese, Traditional Chinese, Japanese, Korean, Spanish, and German.

DeepL then reported a character quota limit. For Portuguese, Arabic, Hindi, Vietnamese, and Thai, this pass used the existing Supericons locale catalogs and repaired weak generic preset text into clear localized descriptions.

The remaining locales are now complete enough for MCP output use, but a future review can replace the repaired generic preset descriptions with richer per-preset translations when more translation quota is available.

Residual Risk

The MCP still does not localize all 20,000+ icon names, by design. Stable icon IDs and library names remain unchanged.

Portuguese, Arabic, Hindi, Vietnamese, and Thai Motion Lab descriptions are clear but less rich than the DeepL-backed locale sets. This is not a protocol risk, but it is a copy-quality improvement opportunity.

Recommended Release Steps

  1. Run the full build and package checks.
  2. Run a small MCP client smoke test with locale on Motion Lab and Converter tools.
  3. After approval, publish the next MCP package and redeploy the hosted MCP service.
