Executive Summary

An SVG icon vector editor is not a smaller Illustrator or Inkscape clone. It is a disciplined production tool optimized for small canvases (typically 16–24 px), stroke consistency, optical balance, themeable output (currentColor), and pack-level coherence. The editor must feel fast, honest, and predictable: every visible control should map to real document behavior.

Core insight: Icon editors succeed when they combine professional vector primitives (select, shapes, pen, nodes, transform, align) with icon-native constraints (grid, keylines, safe area, stroke recipes, small-size preview, SVG linting) and optionally agent-assisted workflows that operate on structured documents rather than raw prompt-to-image blobs.

Research synthesized from:

  • Industry vector editors: Inkscape, Figma, Illustrator, Axialis IconVectors, Vector Ink, Online SVG Editor
  • AI-native icon tools: Recraft, Iconly, PolyGlyph, Clearly, Magnific
  • Supericons Icons Lab internal plans, prototype, and style recipes
  • Developer-focused SVG tooling patterns (live code export, MCP automation, cleanup analysis)

Icon Editor vs General Vector Editor

General illustration tools optimize for arbitrary artboards, rich effects, typography, and complex compositions. An icon editor optimizes for repeatable, themeable, small-size legible assets that ship as code.

Dimension General Vector Editor SVG Icon Editor
Canvas Any size, any units Fixed viewBox (e.g. 24×24), live area, safe padding
Complexity budget Unlimited paths, effects, filters Low node count, no raster embeds, minimal groups
Color model Full palette, gradients, meshes currentColor, stroke/fill roles, theme variants
Primary output Print, illustration, brand systems SVG for UI, icon fonts, React/Vue/Swift components
Quality gate Visual judgment Automated QA: grid fit, stroke width, contrast, complexity
Workflow unit Single artwork Icon pack with shared style recipe

1. Selection & Navigation Tools

Foundation for all editing. Users must be able to identify, isolate, and manipulate objects with zero ambiguity.

Core Select / Move Tool

Default tool. Click to select, drag to move, marquee for area select.

  • Single-click object selection
  • Drag-to-move with live position feedback
  • Bounding box with resize handles (where applicable)
  • Click empty canvas to deselect
  • Selection sync with object/layer list
  • Hit-testing with sensible tolerance at small scales

Craft Multi-Select

Required for align, distribute, group, and batch style edits.

  • Shift+click additive selection
  • Marquee / lasso selection
  • Select all (Ctrl+A)
  • Select same stroke/fill/type
  • Invert selection

Core Zoom & Pan

Icons are tiny; users need to inspect pixel-level detail.

  • Zoom in/out (scroll wheel, pinch)
  • Fit artboard to viewport
  • 100% / 400% / 1600% presets
  • Space+drag pan
  • Zoom to selection

Craft Direct Selection

Select sub-paths or individual points without entering full node mode.

  • Click segment to select
  • Alt+click to select behind
  • Tab through stacked objects

Selection affordances

  • Bounding box: Visual frame with corner/side handles for resize
  • Rotation handle: Optional; many icon sets avoid rotation for grid discipline
  • Center point marker: For optical alignment reference
  • Smart guides: Show alignment to artboard center, edges, and other objects while dragging
  • Hover outline: Pre-select highlight before click

2. Shape Tools

Geometric primitives are the backbone of icon design. Most UI icons are built from rectangles, circles, lines, and arcs — not freehand illustration.

Tool SVG output Typical icon use Priority
Rectangle <rect> with optional rx Cards, windows, buttons, containers, badges Core
Rounded Rectangle <rect rx="..."> App tiles, chat bubbles, modern UI chrome Core
Ellipse / Circle <circle> or <ellipse> Dots, avatars, status indicators, orbits Core
Line <line> Separators, arrows (with caps), simple strokes Core
Polygon <polygon> Triangles, chevrons, simple arrows Craft
Star <polygon> or path Favorites, sparkles, ratings Craft
Arc / Pie <path> arc commands Loaders, progress, partial rings Craft
Ring / Donut Compound or stroke-only circle Loaders, focus rings, radio states Craft

Shape tool behaviors

  • Click-to-place: Single click inserts a default-sized shape at cursor (fast icon drafting)
  • Click-drag: Draw shape with live dimensions
  • Shift-constrain: Perfect squares, circles, 45° lines
  • From-center draw: Alt/Option+drag from center point
  • Corner radius handle: On-canvas radius control for rectangles
  • Convert to path: Flatten primitive to editable path when needed
  • Concentric radius: Inner shape radius = outer radius − gap (icon family rule)

3. Drawing & Path Tools

When primitives are not enough, path tools let designers craft custom silhouettes, connectors, and organic curves — still within icon discipline.

Core Pen Tool

Industry-standard Bezier path creation.

  • Click to place corner points (polyline)
  • Click-drag to place smooth points with handles
  • Close path by clicking first point
  • Finish open path (Esc or explicit action)
  • Live preview line from last point to cursor
  • Prevent accidental selection while drawing

Craft Pencil / Freehand

Free drawing with optional stabilization.

  • Stroke smoothing / stabilizer
  • Auto-simplify on release
  • Best for sketches, rarely for final icon strokes

Craft Arc Tool

Constrained arc segments for loaders and curves.

  • Start/mid/end point arc definition
  • Sweep direction toggle
  • Common preset: 270° loader arc

Advanced Connector Tool

Orthogonal or angled connectors between anchor points.

  • Workflow diagrams, node graphs
  • Auto-routed elbows
  • Arrowhead presets

Path construction helpers

  • Join paths: Merge open endpoints
  • Close path: Connect last point to first
  • Reverse path direction: Affects fill rules and animation
  • Offset path: Expand/contract stroke outline (outline icons)
  • Stroke to path: Convert stroked line to filled shape (for filled variants)
  • Simplify path: Reduce node count while preserving silhouette
  • Split path: Cut at node or point

4. Node & Path Editing

Node editing is what separates a toy shape placer from a real vector editor. Icon designers constantly nudge anchors to achieve optical balance at 16 px.

Node tool capabilities

Action Description Priority
Select nodeClick anchor point on pathCore
Move nodeDrag with optional grid snapCore
Add nodeClick on segment to insert pointCraft
Delete nodeRemove point, preserve path continuityCraft
Convert corner ↔ smoothToggle between corner and smooth Bezier pointsCraft
Adjust handlesDrag control handles independently or mirroredCraft
Break handle symmetryAlt+drag for asymmetric curvesAdvanced
Select multiple nodesShift+click or marquee on pointsCraft
Open/close subpathToggle path closureCraft
Scissors / cut at nodeSplit path at selected pointAdvanced

Node editing UX details

  • Distinct visual language: anchors (square/circle), handles (lines + dots), selected vs unselected states
  • Enter node mode on double-click path or dedicated Node tool (N)
  • Show path direction arrows for debugging fill and animation
  • Numeric inspector for selected node X/Y coordinates
  • Snap nodes to grid, pixel grid, and other nodes

5. Transform Tools

Resize, rotate, flip, and scale objects while respecting icon grid discipline.

Core Move

  • Drag on canvas
  • Arrow keys nudge (1px / 0.5px with modifier)
  • X/Y fields in properties panel

Core Resize

  • Bounding box handles
  • Shift = proportional scale
  • Alt = resize from center
  • Width/height numeric input

Craft Rotate

  • Rotation handle or angle field
  • 15° snap with Shift
  • Often discouraged for grid-aligned icon sets

Craft Flip & Mirror

  • Flip horizontal / vertical
  • Mirror across artboard axis
  • Keyboard shortcuts (H / V)

Advanced Scale / Rotate Dialog

  • Precise percentage scale
  • Rotate around custom origin
  • Transform copy (duplicate + transform)

Advanced Shear / Skew

  • Rare in icons; usually avoided
  • Prefer drawing angled shapes on grid

6. Align, Distribute & Arrange

Optical balance matters more than mathematical centering at icon scale. Alignment tools are daily-use features.

Align to artboard

  • Align left / center / right
  • Align top / middle / bottom
  • Center horizontally & vertically (true center and optical center modes)
  • Fit to safe area / live area
  • Fit to keyline (square, circle, vertical rect, horizontal rect)

Align to selection

  • Align edges and centers between 2+ objects
  • Distribute horizontally / vertically with equal spacing
  • Distribute centers
  • Key object alignment (align everything to one locked reference object)

Arrange (z-order)

  • Bring forward / send backward
  • Bring to front / send to back
  • Drag-reorder in object list

7. Boolean & Compound Operations

Boolean ops let designers build complex silhouettes from simple primitives — essential for subtractive shapes (cutouts, counters, holes).

Operation Result Icon example
UnionCombine shapes into oneMerge overlapping circles into a cloud
SubtractRemove top shape from bottomKeyhole, letter counters, crescent moon
IntersectKeep overlapping area onlyLens shapes, partial overlaps
Exclude / XORKeep non-overlapping areasVenn-style dual forms
DivideSplit into separate paths at intersectionsColoring individual regions

Related compound features

  • Flatten: Merge groups into single path
  • Outline stroke: Boolean-friendly filled outline
  • Live boolean (non-destructive): Nice-to-have; destructive is acceptable for icon editors
  • Pathfinder panel: One-click access to all operations

8. Style & Appearance

Stroke and fill controls define the icon family. For Supericons-style icons, stroke discipline is primary.

Stroke

  • Stroke width (e.g. 1.5px default on 24px canvas)
  • Stroke color (currentColor default)
  • Line cap: butt, round, square
  • Line join: miter, round, bevel
  • Miter limit
  • Dash array (limited use in icons)
  • Stroke alignment: center (default), inside, outside
  • Variable stroke width (rare; illustration feature)

Fill

  • Fill: none / solid / currentColor
  • Fill rule: nonzero vs evenodd (critical after booleans)
  • Opacity per object
  • Gradient fill (optional; many icon sets avoid)

Appearance management

  • Copy style / paste style: Transfer stroke+fill between objects
  • Eyedropper: Pick style from canvas object
  • Style presets: Tied to pack style recipe
  • Global stroke width toggle: Preview icon at 1px vs 1.5px vs 2px
  • Recolor icon: Swap palette while preserving structure

9. Layers, Groups & Object Stack

Icons are simple, but even a 24×24 icon may have 3–12 objects. Users need a trustworthy object stack.

Object stack (minimum viable)

  • List of top-level SVG elements in paint order
  • Click row to select on canvas
  • Rename object (human-friendly label, not raw SVG id)
  • Show / hide visibility toggle
  • Lock / unlock
  • Drag to reorder z-index
  • Delete from list
  • Duplicate object

Groups & hierarchy (V2+)

  • Group / ungroup (Ctrl+G)
  • Nested groups with expand/collapse
  • Isolate group (edit inside without affecting rest)
  • Clip groups / clipping masks (limited icon use)
  • Component / symbol reuse across icons in a pack

10. Canvas, Grid & Viewport

The artboard is a first-class design constraint, not just a viewport.

Artboard defaults (Supericons-aligned)

  • viewBox: 0 0 24 24
  • 2px outer padding → 20×20 live area
  • Default stroke: 1.5px, round cap, round join
  • Default fill: none
  • Default color: currentColor

Overlays & guides

  • Pixel grid: 1px major, 0.5px minor (toggleable)
  • Safe area overlay: Visual margin inside viewBox
  • Keyline guides: Square (~18×18), circle (~20 diameter), vertical rect (~16×20), horizontal rect (~20×16)
  • Center crosshair: Artboard center lines
  • Smart guides: Dynamic alignment hints while dragging
  • Rulers: Optional; less critical at 24px scale
  • Guide lines: User-placed horizontal/vertical guides

Snapping

  • Snap to grid (0.5px or 1px increments)
  • Snap to pixel (whole coordinates)
  • Snap to object edges and centers
  • Snap to keylines and safe area
  • Snap tolerance setting
  • Toggle snap (Ctrl temporary disable while dragging)

11. Icon-Specific Discipline Tools

These features differentiate an icon editor from a generic SVG doodler. They encode professional icon craft as tooling.

Core Style Recipe

Pack-level rules applied to every icon.

  • Canvas size, stroke width, cap/join
  • Corner radius family default
  • Fill mode (outline vs solid)
  • Color role mapping
  • Recipe compliance indicator

Craft Optical Balance

Math center ≠ visual center at small sizes.

  • Optical center nudge presets
  • Visual weight heatmap overlay
  • Compare against keyline templates

Craft Stroke Gap Analyzer

Ensure minimum gap ≥ stroke width between parallel strokes.

  • Highlight collapsed gaps at 16px
  • Suggest widen or merge strokes

Craft Concentric Radius Helper

Nested rounded rects should feel aligned.

  • Inner rx = outer rx − gap
  • Warn on visually inconsistent nesting

Craft Shared Parts Library

Reusable geometry within a pack.

  • Arrows, pluses, checkmarks, dots
  • Insert preset with recipe styles
  • Pack consistency via part reuse

Advanced Modifier System

Compose icons from base + badge.

  • Base glyph + corner badge
  • State overlays (check, x, dot)
  • Non-destructive variant generation

12. Preview & Size Matrix

Icons must be judged at the sizes where they ship. A 24px canvas lie is common — always preview smaller.

Required preview sizes

  • 16px — compact UI, favicons, dense toolbars
  • 20px — common design-system size
  • 24px — primary authoring size
  • 32px — larger controls
  • 48px — touch targets, marketing
  • 128px — docs, store listings, QA review

Preview backgrounds

  • Transparent (checkerboard)
  • Light (white / warm neutral)
  • Dark (black / cool neutral)
  • Brand color swatches
  • High-contrast accessibility check

Preview modes

  • Live sync: edits update all preview cells instantly
  • Side-by-side variant compare (outline vs solid)
  • Pixel preview: rasterized at exact integer sizes
  • Animation preview for loaders and state icons
  • Reduced-motion preview

QA is a creative tool, not just a gate. Automated checks catch issues humans miss at 16px.

Cleanup actions (one-click fixes)

  • Round coordinates to 0.5px or 1px
  • Remove invisible objects
  • Merge duplicate paths
  • Simplify paths (Ramer-Douglas-Peucker or similar)
  • Normalize stroke to recipe default
  • Convert colors to currentColor
  • Strip transforms into path coordinates
  • Minify SVG (export-time)
  • Center icon in viewBox / crop whitespace
Reference: Axialis IconVectors 1.50 introduced "Analyze / Clean Up Icon" as a dedicated workflow — inspect live document, detect off-grid geometry or inconsistent strokes, apply focused fixes. This pattern is ideal for icon editors with agent integration.

14. Import, Export & Code Output

Import

  • SVG file import (parse into editable document model)
  • SVG paste from clipboard
  • PNG / raster import with auto-trace (optional; quality varies)
  • Import from icon library (browse and customize)
  • Preserve or flatten groups on import (user choice)

Export formats

  • SVG — clean, editable, human-readable
  • Minified SVG — production web assets
  • SVG Symbol / sprite — icon systems
  • PNG — raster previews at 16–512px
  • PDF — occasional print/docs need
  • React TSX / Vue SFC — component-ready code
  • SwiftUI / XAML / VectorDrawable — platform-native
  • Icon font — WOFF/TTF generation (advanced)
  • JSON metadata — registry-ready records
  • Pack manifest — batch export for icon families

Live code viewer

  • Real-time SVG/code sync as user edits
  • Copy to clipboard
  • Syntax-highlighted output
  • Diff view (before/after cleanup)

15. Next-Gen & AI-Assisted Tools

Modern icon workflows increasingly blend vector editing with generative AI. The critical requirement: output must remain editable SVG, not flat raster or untouchable blobs.

Design principle: AI should propose, refine, and clean — not replace the document model. Every AI action should be inspectable, undoable, and convertible to normal paths.

Generation

Feature Description Examples in market
Text-to-icon Prompt → icon candidate in a style preset Recraft, Iconly, PolyGlyph
Text-to-SVG vector Prompt → layered, named groups, editable paths Clearly, Iconly Vector Studio, PolyGlyph
Style-locked batch generation Generate 6+ icons in one consistent style Recraft icon sets, Iconly custom templates
Reference-based generation Match an existing icon's style for new concepts Iconly "Use as Reference", Recraft brand style
Image-to-vector Raster/sketch → traced SVG PNG-to-SVG tracers, Clearly, Vector Ink

Auto-shape & smart geometry (high-value next-gen)

Next-gen Auto-Shape for Icons

Recognize intent and propose clean geometric replacements.

  • Rough sketch → snapped rect/circle/arc
  • Wobbly line → straight or 45° diagonal
  • Almost-symmetric shape → mirror and merge
  • Hand-drawn corner → recipe-compliant radius

Next-gen Smart Simplify

Reduce nodes while preserving silhouette readability at 16px.

  • AI-guided path reduction
  • Preserve semantic corners vs noise
  • Preview at target sizes before commit

Next-gen Stroke Normalize

Fix inconsistent stroke widths and caps across imported SVGs.

  • Detect mixed widths
  • Apply recipe stroke in one action
  • Convert outlines to centered strokes

Next-gen Auto-Center & Crop

Remove whitespace and optically center in viewBox.

  • Flood-fill bounding box trim
  • Optical vs geometric center
  • Fit to safe area automatically

Next-gen Metaphor Assistant

Suggest visual metaphors for abstract concepts.

  • "Context compaction" → funnel, stack, compress arrows
  • Agent handoff → relay, swap, dual nodes
  • Generates brief + 3–5 direction thumbnails

Next-gen Variant Generator

Create outline/solid/duotone/badge variants from a base.

  • Outline → filled silhouette
  • Add corner badge modifier
  • State overlays (active, error, disabled)

Next-gen Pack Consistency Coach

Score icon against pack mates.

  • Visual density comparison
  • Stroke weight drift detection
  • Corner radius family check
  • Suggest harmonizing edits

Next-gen AI Refinement Loop

Attach current icon + describe change → refined editable result.

  • "Make the arrow bolder but keep 1.5px stroke"
  • "Simplify the bottom curve"
  • Preserves style recipe constraints

Post-generation editing (Iconly-style tool suite)

  • Recolor to brand palette
  • Adjust stroke thickness slider
  • Smooth edges (multiple algorithms)
  • Background removal (flood fill + manual eraser)
  • Crop and recenter
  • Spot eraser for artifact cleanup
  • Undo/redo on all AI operations

Live editor MCP pattern (IconVectors-style)

  • Agent connects to running editor instance, not detached SVG text
  • Create, draw, edit, inspect, analyze cleanup, render preview, export
  • Document-scoped commands: add rect, update stroke, run QA, export SVG
  • Human approval gate before publishing to registry
  • All agent edits land in undo stack

Agent-safe constraints

  • Agents must respect style recipe bounds
  • Agents cannot bypass QA or publish directly
  • Every agent action produces a human-reviewable diff
  • Structured brief + metaphor proposals before generation

18. What to Deliberately Exclude

Scope discipline is a feature. These are common in full vector suites but wrong for an icon editor V1–V2:

  • Skip Mesh gradients and complex gradient meshes
  • Skip Bitmap filters and Photoshop-style effects
  • Skip Full typography / text tool (text in icons is an anti-pattern)
  • Skip Multi-page document layout / print prep
  • Skip Spray, tweak, sculpt, and illustration-only tools
  • Skip Advanced path effects (offset lorem, lattice deformation)
  • Skip 3D extrusion and perspective grids
  • Skip Marker / arrowhead systems (unless workflow-icon specific)
  • Skip Embedded raster editing
  • Skip Fake controls that don't modify the document
Honesty rule (Icons Lab): If a tool, button, or panel is not wired to the document model, it must be hidden, disabled with a clear unavailable state, or excluded. A smaller honest editor beats a large fake one.

19. Recommended Build Priority

Phased rollout based on Icons Lab prototype state, Inkscape minimum map, and industry patterns.

V1 — Honest Core Editor

  • 24×24 artboard + grid + safe area
  • Select, move, delete
  • Rectangle, circle, line, pen
  • Object stack (reorder, rename, visibility)
  • Properties: position, size, stroke, fill, radius
  • Snap to grid
  • Align to artboard center
  • Size previews (16–128px)
  • Light / dark / transparent preview
  • Export clean SVG
  • Undo / redo

V2 — Icon Craft

  • Node editing (add, delete, move, corner/smooth)
  • Pen curves (click-drag handles)
  • Multi-select
  • Distribute and align between objects
  • Group / ungroup
  • Duplicate, flip
  • Boolean operations (union, subtract)
  • Keyline overlays
  • Style recipe enforcement
  • Basic QA panel (stroke, viewBox, raster, text)
  • SVG import
  • Color controls with currentColor default

V3 — Production System

  • Pack workspace + concept backlog
  • Shared parts library
  • Full QA matrix + cleanup actions
  • Pack consistency scoring
  • Variant generator (outline/solid/badge)
  • PNG + component code export
  • Metadata builder
  • Animation preview (loaders)
  • Batch export pipeline
  • Version history / checkpoints

V4 — Agentic & Next-Gen

  • Agent dock with wired commands
  • MCP live editor integration
  • Metaphor assistant + brief builder
  • Text-to-icon with recipe lock
  • Auto-shape / smart simplify
  • AI refinement loop on editable SVG
  • Analyze / cleanup automation
  • Human review workflow
  • Registry staging export
