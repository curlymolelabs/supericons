Heroicons Library Rollout Plan

This step moves the semantic rollout to the Heroicons library. The goal is to process the whole library, rebuild the shared registry, and only treat the library as closed after it passes the new audit gate.

What this will add

  • A Heroicons batch selector
  • Heroicons review builders
  • A Heroicons approval builder and checker
  • A full Heroicons runner that keeps going until the library is done
  • A final audit report for the completed library

How the rollout works

  • Stage the next Heroicons batch
  • Clear the editor-review queue
  • Clear the visual-review queue
  • Rebuild the approved Heroicons records
  • Rebuild the shared registry
  • Repeat until the whole library is covered

How we stay safe

  • High-confidence editor items can move through quickly.
  • Visual items only move forward when the icon shape really says what we think it says.
  • Unclear icons stay on hold or draft instead of being forced into approval.
  • The final audit makes sure the totals line up and the public registry is still clean.
