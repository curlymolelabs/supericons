# Legal Localization Quality Refinement Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refine the non-English Terms, Privacy, and audit-report copy without changing page code, pricing logic, routing, or product behavior.

**Architecture:** The legal and pricing pages read localized strings from `data/i18n/messages/*.json`; generated copies live in `public/i18n/messages/*.json` and `mcp/public/i18n/messages/*.json`. The implementation changes only targeted catalog strings plus the audit report wording, then regenerates generated catalogs from the data source and runs existing verification scripts.

**Tech Stack:** JSON i18n catalogs, HTML strings stored in JSON, Node.js verification scripts, Vite app runtime.

---

## Confidence And Risk Controls

I am confident this can be done without regressing or breaking code because the change surface is content-only:

- Do not modify `store.js`, route policy, rendering logic, Stripe code, auth code, or package scripts.
- Preserve every existing HTML tag, class, section count, heading count, paragraph count, price value, placeholder, and pipe-delimited list count.
- Edit `data/i18n/messages/*.json` first, then run `node scripts/build-i18n-public-catalogs.mjs` so generated public catalogs match.
- Verify JSON parsing, source/generated catalog parity, commercial localization, i18n catalogs, and route policy before calling the work complete.

Primary risk: malformed JSON or accidental HTML structure drift inside long `bodyHtml` strings. Mitigation: use exact replacements, parse JSON after every edited locale, and run structural checks comparing each localized legal page to English.

@'
const fs = require('fs');
const path = require('path');
const locales = fs.readdirSync('data/i18n/messages').filter((file) => file.endsWith('.json')).map((file) => file.replace('.json', '')).sort();
const messages = Object.fromEntries(locales.map((locale) => [
  locale,
  JSON.parse(fs.readFileSync(path.join('data/i18n/messages', `${locale}.json`), 'utf8')),
]));
const counts = (html) => ({
  sections: (html.match(/<section\b/g) || []).length,
  headings: (html.match(/<h3\b/g) || []).length,
  paragraphs: (html.match(/<p\b/g) || []).length,
  links: (html.match(/<a\b/g) || []).length,
});
const strip = (html) => html.replace(/<[^>]+>/g, ' ').replace(/&[^;]+;/g, ' ').replace(/\s+/g, ' ').trim();
const forbidden = {
  'hi.terms': ['open-source','reverse-engineer','bulk-export','raw','access','sublicense','client work','compiled output','claim','refund','one-time','digital purchases','refundable','access issue'],
  'th.terms': ['CSS animation','sublicense'],
  'ar.privacy': ['premium'],
  'ja.privacy': ['cookie を使わない'],
  'zh-Hans.privacy': ['不使用 cookie'],
  'zh-Hant.privacy': ['不使用 cookie'],
  'hi.privacy': ['cookie-रहित'],
};
for (const page of ['terms','privacy']) {
  const english = JSON.stringify(counts(messages.en.legal[page].bodyHtml));
  for (const locale of locales.filter((locale) => locale !== 'en')) {
    const actual = JSON.stringify(counts(messages[locale].legal[page].bodyHtml));
    if (actual !== english) throw new Error(`${locale}.${page} structure changed: ${actual} !== ${english}`);
  }
}
for (const [key, snippets] of Object.entries(forbidden)) {
  const [locale, page] = key.split('.');
  const text = strip(messages[locale].legal[page].bodyHtml);
  for (const snippet of snippets) {
    if (text.includes(snippet)) throw new Error(`${key} still contains ${snippet}`);
  }
}
console.log('targeted legal localization check: ok');
'@ | node -
