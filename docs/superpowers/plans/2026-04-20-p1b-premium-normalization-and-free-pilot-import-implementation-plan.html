P1-B Implementation Plan

Normalize all premium icons and grow the free pilot

This phase takes the registry from a small proof into a more meaningful working system. The goal is to bring all premium pack icons into the registry shape, keep them protected by default, and grow the free public-safe pilot a little at the same time.

Main Constraint

Premium icon names are not unique across all collections. So this phase cannot assume raw pack names can safely become final SI ids. It needs a stable naming rule that avoids collisions.

What This Phase Does

  • normalize all premium collection icons into the registry shape
  • keep premium records protected by default
  • expand the free pilot to a slightly larger curated public-safe set
  • update the registry build and checks to cover the larger data set

What This Phase Does Not Do

  • it does not make premium records public
  • it does not add runtime access control yet
  • it does not import the full free corpus yet
  • it does not start automation or visual review yet

Implementation Steps

1. Update the verify step first

Change the registry verification so it expects the larger premium and free record counts, then run it before the implementation so it fails for the right reason.

2. Add premium mapping rules

Create one mapping file that explains how each premium collection should become registry data.

3. Normalize premium icons in code

Read the current premium manifest and convert all icons into registry records with stable names and protected visibility.

4. Expand the free pilot

Add a few more carefully chosen free icons that are good public examples.

5. Update preview outputs

Write separate previews for all records, public-safe records, premium records, and free records.

6. Re-run build and checks

Finish by making sure the new registry layer still works inside the full project build.

Success Looks Like

  • all 400 premium icons are represented in the registry
  • premium ids are stable and do not collide
  • the free pilot is larger but still curated
  • public previews still show only public-safe records
  • full build still passes
