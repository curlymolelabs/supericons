P1-K Bulk Purpose-Chip Scale-Up Plan

This step grows the purpose-chip pilot from the small reviewed set to the full 150-icon set, while keeping the quality rules in place.

Goal

Cover all 150 icons in the three purpose-chip groups. The 30 approved icons stay approved. The remaining icons get a stronger first draft and a clear next step.

Why this matters

We already proved that the semantic format works and that approved records help search. The missing piece is scale. Right now, 114 of the 150 icons are still waiting in a rough first-pass state.

What will happen

  1. Keep the approved, hold, and reviewed-draft icons exactly as they are.
  2. Create stronger automation-staged semantic records for the remaining 114 icons.
  3. Give each staged icon a simple next step like editor review, visual review, text review, or manual tightening.
  4. Create a clear summary showing the full 150-icon coverage picture.
  5. Add checks so the new staged set stays consistent.

Important limit

This step does not publish all 150 icons as approved. It only stages the remaining icons safely. The reviewed and approved work stays protected.

Expected result

  • Every icon in the 150-icon set will be accounted for.
  • The reviewed subset will remain trusted and unchanged.
  • The remaining icons will have better first drafts than the old generic lane filler.
  • We will be able to see which icons are closest to approval next.

Checks

  • npm run build:purpose-chip-scale-up
  • npm run verify:purpose-chip-scale-up
  • npm run build:purpose-chip-pilot
  • npm run verify:purpose-chip-pilot
  • npm run build
