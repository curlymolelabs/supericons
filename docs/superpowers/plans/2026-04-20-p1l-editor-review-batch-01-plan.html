P1-L Editor Review Batch 01 Plan

This step moves the clearest staged icons forward first, instead of trying to solve every remaining icon at once.

Goal

Take the 27 staged icons that are already marked as ready for editor review and move them into the approved import path.

Why this matters

Not all of the remaining icons are equally hard. Right now, 27 are already strong enough for a short editor pass, while 19 still need visual review and 68 still need text-only review because their visual payloads are missing.

What will happen

  1. Build one review batch for the 27 strongest staged icons.
  2. Turn that batch into reviewed records that are clean and safe to share.
  3. Add the batch to the promotion path.
  4. Rebuild the approved set and the coverage summaries.
  5. Create a visual contact sheet so the batch can be checked easily later.

What this step does not do

  • It does not handle the 19 icons that still need visual review.
  • It does not handle the 68 icons that still rely on text-only review.
  • It does not reopen the older hold queue yet.

Expected result

The approved set should grow, the remaining staged queue should shrink, and the next unresolved work should be more concentrated and easier to plan.
