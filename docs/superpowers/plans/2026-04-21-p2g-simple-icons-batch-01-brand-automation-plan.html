Simple Icons Batch 01 Plan

This step starts the next library after MingCute. The goal is to handle Simple Icons the right way: as official brand marks, not as normal app action icons.

What This Step Will Do

  • Set up a first batch for Simple Icons.
  • Use brand-friendly meaning rules instead of generic UI rules.
  • Stage a first group of icons for review.
  • Promote a first approved group into the shared registry.

Why Simple Icons Needs Different Rules

MingCute mostly contains regular app icons like search, close, upload, and menu. Simple Icons is different. It mostly contains company, product, service, and platform logos.

That means we should not tag a brand mark like GitHub, Stripe, or Spotify as if it were a normal action icon. Instead, we should describe it as the official mark for that brand or product.

Main Work

  • Add a Simple Icons batch 01 config.
  • Teach the shared automation code how to build brand records.
  • Add approval scripts for Simple Icons.
  • Build the batch, approve a first slice, and rebuild the registry.

What Counts As Success

  • The batch builds with the shared automation system.
  • The records stay safe for public sharing.
  • The first approved Simple Icons records enter the free registry path.
  • The full project build still passes.
