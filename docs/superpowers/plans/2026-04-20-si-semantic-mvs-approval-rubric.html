Working Standard

SI Semantic Minimum Standard

This document defines the minimum quality bar a semantic icon record must meet before it can move out of draft review work and toward approved import.

The goal is not perfection. The goal is a clear floor for what counts as useful, honest, and safe enough to trust.

What This Standard Is For

  • stop vague approvals
  • stop overconfident tagging
  • make approval decisions more consistent
  • keep records useful for real builders, not just technically filled in

The Main Test

A record passes the minimum standard if it is specific enough to help someone choose the icon, honest enough to admit ambiguity, and grounded enough in the actual visual shape and context.

The 8 Approval Gates

1. Identity is complete

The record needs a stable icon id, source library, source name, and label.

2. The visual read is grounded

If a real icon image is available, the record should say what the icon appears to show, what visual motifs are present, and how ambiguous it is.

3. The purpose is specific

The purpose should explain the recommended use, not just repeat the icon name or describe the shape.

4. use_when helps a real decision

This should help someone know when the icon is a good choice in a real interface.

5. avoid_when prevents bad use

This should help someone avoid confusing or misleading use.

6. Tags and synonyms are honest

They should make the icon easier to find without stretching the meaning too far.

7. Lane fit is confirmed or corrected

If the icon was seeded in the wrong group, the review should correct that instead of preserving it by habit.

8. Confidence is fair

The confidence level should match how clear or ambiguous the icon really is.

Approval Outcomes

Approve for import

The record is useful, honest, and clean enough to move forward.

Hold for editor review

The record is close, but still needs tightening in one or two places.

Keep as reviewed draft

The review added value, but the icon is still too context-sensitive to approve.

Rewrite before reconsidering

The current semantic frame is still too misleading or too broad.

Confidence Guidance

  • High confidence: the icon is clear, the purpose is specific, and confusion risk is low.
  • Medium confidence: the icon is still useful, but context matters a lot or two meanings remain plausible.
  • Low confidence: the recommendation is still too fragile and should not move into approved import.

Simple Rule

A record passes the minimum standard if it clears all 8 gates at an acceptable level, is at least medium-confidence, and openly acknowledges the ambiguity that still remains.
