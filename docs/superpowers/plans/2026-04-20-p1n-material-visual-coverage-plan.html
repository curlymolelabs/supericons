P1-N Material Visual Coverage Plan

This step fixes the last big blocker by giving the remaining Material icons real SVG payloads for proper visual review.

Goal

Fetch local SVG copies for the 68 remaining Material purpose-chip icons so they can move out of text-only review.

Why this matters

The remaining queue is no longer blocked by semantic design. It is blocked because those icons only have names and metadata, not local SVG payloads. That makes visual review impossible.

What will happen

  1. Create one repeatable seed step for the remaining Material icons.
  2. Fetch local SVG snapshots for them.
  3. Rebuild the Material export manifest.
  4. Rebuild the purpose-chip summaries.
  5. Measure how much of the text-only queue becomes visual-ready work.

What this step does not do

  • It does not approve those icons yet.
  • It does not finish their semantic review yet.
  • It only solves the missing-visual problem first.

Expected result

The remaining queue should stop being a text-only problem and become a normal visual-review problem instead.

Checks

  • npm run seed:purpose-chip-material-coverage
  • npm run build:material-export-manifest
  • npm run build:purpose-chip-scale-up
  • npm run verify:purpose-chip-scale-up
  • npm run build
