P1-M Visual Review Batch 01 Plan

This step handles the 19 icons that already have real visual payloads and still need a proper visual judgment before approval.

Goal

Review the 19 icons in the current visual-review queue, approve the ones that clearly fit, and keep the rest in the right hold or draft bucket.

Why this matters

These icons are the next best batch because they already have renderable SVGs. That means they can be judged properly now, instead of waiting behind the larger text-only queue.

What will happen

  1. Build one visual-review batch for the current 19 icons.
  2. Create a contact sheet for visual checking.
  3. Write reviewed records for the icons that hold up.
  4. Update the promotion path with approvals, holds, or reviewed drafts.
  5. Rebuild the approval and coverage summaries.

What this step does not do

  • It does not solve the 68 text-review icons yet.
  • It does not reopen the older hold queue yet.
  • It does not force broad or unclear icons into approval.

Expected result

The approved set should grow again, the visual-review queue should get much smaller, and the remaining unresolved work should mostly be the text-only slice.
