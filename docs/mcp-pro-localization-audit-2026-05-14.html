Findings

Pass Local multilingual search search_icons for settings, privacy, and security terms across English, Chinese, Japanese, Korean, Spanish, and Arabic. Returned relevant icons, including settings, lock, and related results. Localized queries should find the same concepts as English queries. No fix needed.

Pass Pro workflow tools Motion Lab preset list, recipe export, animated SVG export, combined animation output, Converter option inspection, SVG input inspection, and SVG-to-PNG conversion. All checked Pro workflow paths returned usable output locally with the temporary Pro key. Pro workflow tools should work when a valid Pro key is supplied. No fix needed.
Pass Premium pack policy wording Tool descriptions and Pro-key search behavior. MCP wording now states that Pro keys unlock workflow tools and that premium pack icon search is not exposed through MCP yet. Searching a premium pack library did not expose pack icons. The MCP should not promise premium pack icon search unless that feature is actually exposed. No further wording fix needed.
Regression Live hosted MCP search fallback Live hosted search_icons with Chinese settings text and no locale, plus Bootstrap solid-style search. The live hosted server returned no results for these two cases. The hosted server should fall back to its local public index when the search gateway returns no useful results. Fixed in local source by improving mcp/remote-server.js. Railway still needs to be redeployed.
Regression Live hosted MCP recommendations Live hosted recommend_icons for settings-page slots in all supported locales. The live hosted server returned weak matches for several slots, such as layout or alignment icons for privacy/theme/account slots. The hosted server should match local behavior and return account, bell, shield/lock, palette/theme, and language icons. Local source already has the corrected rules. Railway still needs to be redeployed.
Warning Published npm package Installed supericons-mcp@latest in a temporary folder and tested settings-page recommendations. The published package is version 0.4.4, but it still returned a weak privacy/security recommendation in this test. The next published package should match the corrected local source. Publish the next patch version after approval.

Fixes Applied

  • Updated mcp/remote-server.js so hosted MCP search can fall back to its local public index whenever the hosted search gateway errors or returns no useful results.
  • Updated mcp/remote-server.js so the local fallback index includes solid icons from icon-index-solid.json.
  • Verified existing local recommendation rules for settings-page slots across all supported locales.
