Proposal Plan

MCP, Motion Lab, Converter, and Docs Expansion

This proposal aligns MCP copy with the real entitlement model, maps the current MCP surface, and defines how Motion Lab and Converter should become agent-accessible Pro workflow tools.

Primary Recommendation

Make MCP a complete workflow surface instead of a search-only feature. Keep icon retrieval as the entry point, then extend Pro value through Motion Lab and Converter access for agents.

Exact Copy Sources

The current premium statement is in the in-app MCP hub.

Free icons work out of the box. Premium collections unlock with a Pro subscription or API key.

The stale MCP tool description is in the MCP server package.

Search 19,000+ icons across 9 libraries using AI-powered synonym expansion. Returns matching icons with SVG code. Premium collections require a Pro API key.

Why It Needs Correction

  • An API key is not the source of premium access. It carries account entitlement.
  • Pack buyers are missing from the current premium copy.
  • The server count claim is out of sync with broader product messaging.
  • The premium setup path is incomplete because the MCP page does not explain Dashboard API key generation.

Recommended Copy

Free icons work out of the box. Premium collections are available when your account has Pro or purchased pack access and your MCP client is connected with your Supericons API key.

Preferred launch copy for the search tool if implementation is aligned:

Search 20,000+ free icons across 10 libraries. Premium collections are available when your API key is linked to a Pro subscription or purchased packs.

Safe Interim Copy

If count and library totals are not fully aligned in MCP yet, ship truth-first wording instead of a risky numeric promise.

Search free icons across the libraries currently supported by Supericons MCP. Premium collections are available when your API key is linked to a Pro subscription or purchased packs.

Proposed MCP UX Flow

Free path Discover MCP, copy config, restart client, search icons, retrieve SVG.
Premium path Sign in, subscribe to Pro or buy a pack, generate API key in Dashboard, add SUPERICONS_API_KEY, restart client, use premium tools.
Recovery path If key is invalid or revoked, MCP error points back to Dashboard API keys and setup docs.

Required States

  • Anonymous free setup
  • Signed in but no entitlement
  • Entitled but no API key yet
  • Valid premium key
  • Invalid or revoked key
  • Tool unavailable or unsupported request
  • Premium workflow requested without access
