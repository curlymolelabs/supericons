# Supericons Affiliate Program Inventory

Date checked: 2026-06-18

This note tracks affiliate, referral, partner, and creator-program opportunities for the 50 Supericons AI tool logos. The intended product behavior is preview-panel only: do not embed affiliate URLs, referral URLs, disclosure copy, or commerce metadata into SVG files, portable icon schemas, public icon indexes, or downloadable icon payloads.

## Status Key

| Status | Meaning | Use in preview panel |
| --- | --- | --- |
| `ready_exact_affiliate` | Official program found for the same brand/product, with cash commission or paid referral language. | Candidate for a subtle CTA after Supericons has its own approved link. |
| `official_referral_or_partner` | Official referral, partner, ambassador, creator, or credit program exists, but it is not a simple public affiliate link. | Use only as an organic or partner CTA unless the commercial terms are approved. |
| `related_not_exact` | Official affiliate program exists for the parent company, sibling product, or broader platform, but not the exact icon product. | Do not monetize until the destination is clearly matched to the icon intent. |
| `conflict_or_third_party` | Search results show third-party or similarly named programs that may not be the exact brand. | Do not wire without manual confirmation. |
| `program_closed_or_paused` | The brand has an official page or support answer saying the affiliate program is closed, paused, ended, or not accepting new affiliates. | Organic official-site CTA only unless the program reopens. |
| `no_public_program_found` | First-pass search did not find an official public affiliate program. This is not proof that none exists. | Organic official-site CTA only. |

### Cross-Library Commerce Model

Use one server-managed commerce profile per brand, with many icon IDs mapped into it. This keeps monetization consistent across duplicate logos and prevents each library from growing its own link rules.

```js
{
  brandSlug: 'shopify',
  iconIds: ['simpleicons:shopify'],
  partnerStatus: 'affiliate_pending',
  officialUrl: 'https://www.shopify.com/',
  destinationUrl: '/go/shopify',
  ctaLabel: 'Start a store',
  ariaLabel: 'Start a store with Shopify',
  rel: 'sponsored noopener noreferrer',
  disclosureRequired: true,
  seo: {
    title: 'Shopify logo icon - ecommerce store builder',
    description: 'Shopify logo profile with ecommerce, online store, checkout, and storefront intent tags.',
    sameAs: ['https://www.shopify.com/'],
    intentTags: ['ecommerce platform', 'online store builder', 'sell online', 'shopify logo'],
    relatedIconIds: ['simpleicons:stripe', 'simpleicons:paypal', 'simpleicons:bigcommerce']
  },
  sources: ['https://www.shopify.com/affiliates'],
  verifiedAt: '2026-06-18'
}
```

Search and AI-agent discovery should use the brand profile and icon detail page, not the SVG payload. Good searchable fields are `brandSlug`, `officialName`, `alternateNames`, `productCategory`, `intentTags`, `sameAs`, `relatedIconIds`, and `lastVerifiedAt`. Paid status should never silently boost icon search ranking.

## Preview-Only Metadata Shape

Affiliate and search metadata should live in app-only preview configuration or a server-managed commerce profile, not in the SVG or portable icon export.

```js
{
  iconId: 'si:base44',
  partnerStatus: 'affiliate_pending',
  officialUrl: 'https://base44.com/',
  destinationUrl: '/go/base44',
  ctaLabel: 'Build real apps',
  ariaLabel: 'Build real apps with Base44',
  rel: 'sponsored noopener noreferrer',
  disclosureRequired: true,
  seo: {
    title: 'Base44 logo icon - AI app builder',
    description: 'Base44 Supericons logo profile with AI app builder category, official link, and related builder tools.',
    sameAs: ['https://base44.com/'],
    intentTags: ['ai app builder', 'vibe coding', 'no code app builder', 'build apps with ai'],
    relatedIconIds: ['si:lovable', 'si:bolt', 'si:vercel-eve']
  },
  sources: ['https://base44.com/affiliates'],
  verifiedAt: '2026-06-18'
}
```

Implementation notes:

- Use approved partner links through a redirect such as `/go/base44`, so links can be changed, disabled, measured, and labeled without changing icon files.
- Keep the visible preview UI subtle: one small CTA near the icon name is enough for the main Supericons utility flow.
- Add disclosure near paid CTAs when a paid affiliate or sponsored relationship is active.
- For SEO and AI-agent discovery, prefer dedicated icon detail pages or preview-panel structured data using `SoftwareApplication`, `Organization`, `sameAs`, and intent tags.
- Do not let paid status silently affect search ranking. Search relevance should stay organic; paid CTAs can appear when the selected icon already expresses relevant product intent.
