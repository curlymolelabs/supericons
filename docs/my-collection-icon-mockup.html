My Collection – Two Icon Versions

Hover both "My Collection" rows to trigger the animations. No JS, pure CSS keyframes, matching the sidebar pattern exactly.

Version 1

Existing folder icon + sparkles

The folder shape you already have. On hover, three 4-point star sparkles ignite across the top of the folder in a left-to-right cascade, like precious items inside are shining through. The folder itself gets a subtle pride-pulse scale. Sparkles represent: this is your curated treasure, not just a generic folder.

Version 2

Supericons logo mark – fireball launch

The Supericons S-mark (orange, facing right like a bolt of motion). On hover it coils back slightly, then fires rightward in a burst, squashing on launch and overshooting before snapping back. A ghost trail evaporates behind it. This says: this is Your Collection, powered by Supericons, moving fast.

Version 1 animation breakdown
  • v1-spark-1 (0ms, 700ms) – left sparkle cross ignites, peaks at 20%, fades by 100%
  • v1-spark-2 (120ms delay) – center sparkle, slightly taller cross, slightly longer
  • v1-spark-3 (240ms delay) – right sparkle, cascade complete, stagger = 120ms apart
  • v1-folder-body (0ms) – 1.07x scale pride pulse, spring easing
  • Easing: Decelerate in, Accelerate out per sparkle (flash feel, not bounce)
Version 2 animation breakdown
  • v2-logo-mark (0ms, 620ms) – coils back −1px at 18%, bursts right to +7px at 62%, snaps back to rest
  • v2-trail (40ms delay) – ghost behind logo fades in as the mark surges, then evaporates leftward
  • squashX at 0.82 on coil, stretchX at 1.18 on burst – classic squash-and-stretch for velocity feel
  • Easing: cubic-bezier(0.175, 0.885, 0.32, 1.275) – strong elastic overshoot on the launch
  • Logo uses orange brand color directly (#ff4f00 / currentColor override) matching the active state
