The destination

Supericons evolves from an icon library into a living map of programmatic icons: every icon an interactive, schema-backed, payment-capable portal to the thing it represents, curated in real time by agents and governed by human taste. The moat is the living ecosystem and its compounding data, which no snapshot can copy.

Five tracks, one loop

Each track feeds a different part of the engine. Now is in motion or immediately startable. Later is entry-gated, never calendar-gated.

Next

Expressive originals (ship it, burnout, celebration) plus the design-record pilot: new icons enter with two-tier schema. Ring 0 begins.

Later

New-icons section on the site (first-seen dates reconstructable from git, nothing blocks adding now).

Reach

feeds: search volume, the raw fuel
Now

Fixed: official MCP registry at 0.4.22 (was deprecated 0.4.1 for weeks). Glama, Smithery, MCP.so updated. Check: whether VS Code's @mcp gallery already lists us via the registry.

Next

Later

Open VSX / VS Code extension only if evidence shows the registry route misses those users. An extension is a product, not a listing.

Identity

feeds: credit, analytics, conversion
Now

Nothing personal is possible: 95% of traffic is anonymous, 2 identities account-linked. Conversion is unmeasurable by construction.

Next

Rung 1: self-service free keys, synced collections, agent retrieval tool. Hard constraint: a key must be obtainable and usable inside an agent conversation, or registration stays flat. Attribution choice built into issuance.

Later

Rung 2 Gap Report (your searches, your zeros, guided retry, MCP surface from day one), then paid analytics only after free proves engagement.

Creation

feeds: the bridge + taste gate
Now

Concierge loop: owner picks from Demand Inbox, draws in Icons Lab, publishes with credit. Proves cadence with zero new engineering.

Next

Build the bridge: zero-result page offers "make it yourself", Icons Lab accepts the prefilled brief. Smallest piece of the whole vision that can ship.

Later

Community publish pilot, credit-only, schema attached. License class for creator-owned icons decided before the first publish.

Economy

feeds: wallet, closes the flywheel
Now

Nothing. Deliberately. Credits and named credit are the only rewards until transaction volume clears payout overhead (the Kickbacks lesson: 27 countries of tax for $6 average payouts).

Next

Design-only: credit accounting rules, one page. x402 rails already spiked in phase 0.

Later

Paid icons, plan-tiered royalty cuts, ring 5 publishers through the taste gate, aggregate trends product. Owner decides all pricing (VC-9).

The dependency spine

The order is the strategy. Each gate unlocks the next; skipping one builds machinery that runs empty.

1
Second channel carrying real trafficAnthropic approval, VS Code gallery presence, or organic growth. Diversification is a tracked workstream (D-043).
96.5% on one directory is the only measured existential risk. Volume is also the input every other track consumes.
2
The loop closes once, end to end, with a strangerGap surfaced, icon created, taste-gated, published, found by someone else, credited. Bridge + concierge gets us there.
Turns the living map from a document into a system with evidence. The single most convincing artifact for users, directories, and future contributors.
3
Rung 1 identity liveFree keys usable inside agent conversations, collections, attribution coverage rising.
Unblocks credit that persists, personal analytics, measurable conversion, and the contribution funnel. Everything personal is gated here.
4
Volume roughly 10xSearch and take volume where rankings are dense, analytics are interesting, and fees exceed payout overhead.
The honest gate for the economy. Popularity ranking (parked to Aug), paid analytics, and royalties all become real here, not before.

Built on a flywheel already spinning rather than hoping to start one. Automatic publish stays private-library only unless VC-5 is deliberately amended.

The rules that outlast every milestone

Free stays free. The static library is the growth engine, never a concession.
The moat is living data. Usage intelligence never ships in a public bundle.
Honest beats impressive. Zeros over fabricated relevance; populations stated; no claim without proof.
Human taste gates agent scale. Fast is fine; absent is a charter amendment.
Agents are first-class. Every capability states its MCP surface; x402 for agents, cards for humans.
Identity is a reward, never a wall. Keys attribute; they do not gate.
Ship by dependency, not calendar. Entry criteria, never dates.
Evidence before architecture. New layers exist only when measured demand proves the current one cannot serve.
