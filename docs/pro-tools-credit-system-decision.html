2. Credit System Architecture

Principle: Capability-based, not abstract currency. Users buy "5 AI generations" not "500 credits." Concrete bundles convert better than abstract tokens.

Credit Types

TypeSourceExpiryRollover
PACK_CREDIT1/month with Pro sub6 monthsNo
AI_CREDITTBD/month with Pro subMonthly resetNo

Schema: Append-only Ledger

Credits tracked via immutable ledger, not mutable counters. Enables auditability and dispute resolution.

credit_ledger
  id          UUID PRIMARY KEY
  user_id     UUID REFERENCES auth.users
  credit_type TEXT ('PACK_CREDIT' | 'AI_CREDIT')
  amount      INT  (+grant / -debit)
  reason      TEXT ('monthly_grant' | 'pack_redeem' | 'ai_use' | 'purchase' | 'expired')
  expires_at  TIMESTAMPTZ
  created_at  TIMESTAMPTZ DEFAULT now()
