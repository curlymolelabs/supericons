# Supericons Single Icon License Draft

Date: July 6, 2026
Status: Draft for x402 beta planning. This is not legal advice and should be reviewed before mainnet launch.

## Scope

This draft covers one paid animated icon purchased through the Supericons single-icon purchase flow, including purchases made through x402 by a human, an agent acting for a human, or an automated agent acting for an organization.

## Licensee

The licensee is the person or organization that controls the paying wallet or account at the time of purchase.

If an agent buys on behalf of a person or organization, the licensee is the person or organization that authorized the agent to make the purchase. The agent is only a tool used to complete the transaction.

If a receipt is tied only to a wallet address, the wallet controller is responsible for keeping enough receipt information to prove the purchase later.

## Grant

Supericons grants the licensee a non-exclusive, worldwide, perpetual license to use the purchased icon in one end product, client project, website, app, presentation, internal tool, or software repository.

The license includes the delivered SVG and any delivered animation CSS for that icon.

## Allowed Uses

The licensee may:

- Use the icon in personal, commercial, client, and internal projects.
- Modify the icon for the licensed project.
- Include the icon in source code or built application files for the licensed project.
- Let an authorized agent place, adapt, or copy the icon into the licensed project.
- Show the icon inside screenshots, demos, documentation, and marketing for the licensed project.

## Not Allowed

The licensee may not:

- Resell, sublicense, or redistribute the icon as a standalone asset.
- Publish the icon in an icon pack, template library, design kit, marketplace item, or asset database.
- Share the raw source as a reusable asset outside the licensed project.
- Use the icon to build a competing icon library, stock asset product, or training set.
- Remove ownership or receipt records to hide how the icon was obtained.

## Agents and Wallets

An agent may buy and use the icon only for the wallet controller or account holder that authorized the purchase.

The agent should keep the x402 payment response, settlement reference, or receipt data when available. That receipt data is the practical proof of purchase for wallet-only flows.

## Support and Disputes

For settlement disputes, paid-but-not-delivered cases, duplicate charge concerns, or license questions, contact hello@supericons.dev with receipt data and the requested icon name.

## Refunds

Refunds are not automatic in the beta. Support may review duplicate charges, delivery failures, or mistaken purchases case by case.

## No Warranty

The icon is provided as-is. Supericons may improve delivery systems, documentation, and receipt handling over time without changing the license already granted for a valid purchase.
