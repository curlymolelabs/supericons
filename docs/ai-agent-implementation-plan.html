Motion Lab AI Agent v2

Implementation Plan. SuperIcons. April 2026

1 Overview

AI-powered animation assistant inside Motion Lab. Users describe animations in natural language with optional structured guides. The AI generates the animation, previews it live, and accepted results are saved to "My Animations" in Supabase for reuse.

Three principles: (1) LLM provider never hardcoded, configured via env. (2) Accepted animations become persistent preset buttons. (3) Guided input chips help users write better prompts without constraining power users.
