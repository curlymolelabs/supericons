# Supericons

Use Supericons when a task needs SVG icons, icon recommendations, icon library choices, or icon IDs for a user interface.

## What To Use It For

- Search for icons by meaning, object, action, or UI role.
- Preview icons visually before choosing one.
- Retrieve a specific SVG icon by library and icon ID.
- Recommend icons for navigation, dashboards, buttons, empty states, and settings screens.
- List available icon libraries before choosing a style.

## Good Prompts

- Search for a database icon.
- Show me a visual preview of icons for ai slop.
- Recommend Lucide outline icons for a dashboard sidebar.
- Get the SVG for the Tabler settings icon.
- Find icons that mean upload, sync, and success.

## Notes

- Free public icon search does not need a Supericons API key.
- Use visual previews when the user asks to see, compare, choose, or inspect icons before final selection.
- Pro features may need `SUPERICONS_API_KEY` in the user's private OpenClaw or MCP environment.
- Do not put real API keys in shared project files, public screenshots, or chat messages.
